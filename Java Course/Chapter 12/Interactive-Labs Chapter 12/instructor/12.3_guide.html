COP1800 · Java Programming I · Lab 12.3

The clinic texts that never reach (305) 555-0199

Objectives

  • Trace a recursive method that splits a string with indexOf() and substring()
  • Write a recursive string method that shrinks its argument by one character each call
  • Return a built-up result instead of printing pieces, so the caller can store it

Requirements

  1. R1 digitsOnly() returns the cleaned string and prints nothing, so the caller can store it.
  2. R2 Base case: an empty string has no digits, so digitsOnly("") returns "".
  3. R3 Recursive case: look at one character (the first, or the last), keep it only if Character.isDigit() says it is a digit, and join it with what digitsOnly() returns for the rest of the string, one character shorter.
  4. R4 No loops and no replace, replaceAll or split: the recursion does the work. Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. Trace the book's removeDashes("305-555"). List the calls in order with their arguments, and say which calls print.

    removeDashes("305-555") finds the dash at 3 and calls removeDashes("305"), which prints 305, then removeDashes("555"), which prints 555. The first call prints nothing itself; only the base cases print.

  2. What does removeDashes("(305) 555-0199") print, and why can't the clinic save that result in a variable?

    (305) 5550199: only the dash is removed. And the method is void; it prints the pieces as it goes, so there is no value to assign to a variable.

Solution

PhoneCleaner.java
public class PhoneCleaner
{
    // The book's version (pp. 497-498): it prints the pieces between dashes.
    // It returns nothing, so the clinic can't store the cleaned number.
    public static void removeDashes(String s)
    {
        int dashLoc = s.indexOf('-');
        if (dashLoc == -1)
        {
            System.out.print(s);
        }
        else
        {
            removeDashes(s.substring(0, dashLoc));
            removeDashes(s.substring(dashLoc + 1));
        }
    }

    // Returns only the digits of s, in order: "(305) 555-0199" -> "3055550199".
    public static String digitsOnly(String s)
    {
        if (s.length() == 0)
            return "";
        char first = s.charAt(0);
        String rest = digitsOnly(s.substring(1));
        if (Character.isDigit(first))
            return first + rest;
        else
            return rest;
    }
}

Walkthrough

removeDashes() splits around the first dash with indexOf() and handles both halves recursively, like breakIntoWords() (Figure 12-14). It can only display, and only dashes. digitsOnly() uses the other technique from section 12.3: shrink the string by one character per call, as reverseString() does (Figure 12-16). The base case is the empty string, which every chain reaches because each call removes one character. The recursive case decides about one character and joins it to the returned result for the rest: first + rest keeps the digit in front, so the order is preserved. first + rest is a char plus a String, which is string concatenation. Returning instead of printing lets the caller store, compare or count the result (the test prints stored.length()). Working from the last character (s.substring(0, s.length() - 1), with the digit added after the result) is equally correct.

public class TestPhoneCleaner
{
    public static void main(String[] args)
    {
        String[] typed = { "305-555-0199", "(305) 555-0199", "305.555.0199",

Messages students see when a check fails

C1 · Returns the result, prints nothing

Don't print inside digitsOnly(): return the string, so the clinic can store it and the caller decides whether to display it.

C2 · An empty string is the base case

Every call shortens the string by one character, so the chain always ends at the empty string. Test for it first (s.length() == 0 or s.isEmpty()) and return an empty string.

C3 · Keeps only digits

Decide about one character with Character.isDigit(...): keep it if it is a digit, drop it otherwise. That handles dashes, spaces, dots and parentheses in one rule.

C4 · The recursive call gets a string one character shorter

Call digitsOnly() on the rest of the string, one character shorter: s.substring(1) (everything after the first character), as reverseString() shortens its string in Figure 12-16.

C5 · Recursion does the work

This lab practises recursion: remove the loop or library shortcut and let each call handle one character.

Progressive hints

  1. Think of the string as one character plus the rest. You only decide about one character; the recursive call cleans the rest.

  2. s.charAt(0) is the first character and s.substring(1) is everything after it. When is there no first character to look at? That is the base case.

  3. Build the answer from the returned value: if the first character is a digit, put it in front of what the call on the rest returns; otherwise return that result unchanged.

Reflection: questions and model answers

  1. Your recursive call always gets a string one character shorter. Explain why that guarantees the base case is reached, and how many calls digitsOnly("305-555") makes.

    Each call removes one character, so the length goes 7, 6, 5, ... down to 0, and length 0 is the base case. That is 8 calls: one per character plus the call with the empty string.

  2. Why is returning a String a better design for the clinic than the book's version that prints?

    A returned value lets the caller decide what to do with it: store it in the records, compare it, check it has 10 digits, or print it. A method that prints can only display; its result can't be saved or tested.

Extension

Numbers typed with a country code, like +1 (305) 555-0199, clean to 11 digits. Write forTexting(String s) that calls digitsOnly() and drops a leading 1 when the result has 11 digits. Should that rule live inside the recursion? Why not?
