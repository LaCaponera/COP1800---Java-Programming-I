Lab 12.2: The playlist tool that crashes on an empty set

Recursive math: the right base case, and a return type big enough for the answer

Estimated time: about 25 minutes. Reading: Ch. 12, section 12.2 (pp. 489–495).

You will be able to:

  • Choose a base case that is the smallest input a recursive method accepts (0! = 1)
  • Follow how waiting calls on the call stack finish in reverse order and combine their results
  • Write a recursive method with two parameters that returns a value

How to complete it

  1. Open the lab page (12.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (PlaylistMath.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; both methods have a clear base case before the recursive case; no loops or factorial division in arrangements().

The checks on the lab page give you feedback; they are not your grade.
