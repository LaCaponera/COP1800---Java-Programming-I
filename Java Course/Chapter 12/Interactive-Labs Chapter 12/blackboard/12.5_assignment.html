Lab 12.5: The savings calculator the IT team wants as a loop

Recursive and iterative versions of the same method give the same answers

Estimated time: about 25 minutes. Reading: Ch. 12, section 12.5 (pp. 500–503).

You will be able to:

  • Map the parts of a recursive method (base case, recursive step, smaller argument) onto a loop
  • Write an iterative method that gives exactly the same results as a recursive one
  • Weigh recursion against iteration: overhead, call-stack depth and clarity

How to complete it

  1. Open the lab page (12.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (SavingsPlan.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; the loop mirrors the recursive method part for part; the recursive version is unchanged.

The checks on the lab page give you feedback; they are not your grade.
