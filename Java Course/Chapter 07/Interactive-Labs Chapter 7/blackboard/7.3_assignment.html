Lab 7.3: The marina list that files zephyr after Zodiac

Comparing Strings: equals(), equalsIgnoreCase(), compareTo(), and empty versus null

Estimated time: about 25 minutes. Reading: Ch. 7, section 7.3 (pp. 241–246).

You will be able to:

  • Choose between equals() and equalsIgnoreCase() for a comparison typed by people
  • Use the sign of compareTo() to decide which of two Strings comes first
  • Explain why compareTo() puts every capital before every lowercase letter
  • Tell an empty String from a null String, and test for null with == before calling any method

How to complete it

  1. Open the lab page (7.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (MarinaRegistry.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the null test comes first and reads clearly; comparisons test the sign of compareTo(), not a specific number.
