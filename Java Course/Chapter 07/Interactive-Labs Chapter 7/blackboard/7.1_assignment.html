Lab 7.1: The bridge door that locks out its own officer

String variables are references: == compares where text is stored, equals() compares what it says

Estimated time: about 20 minutes. Reading: Ch. 7, section 7.1 (pp. 237–238).

You will be able to:

  • Explain why == on two String variables compares memory addresses, not the characters
  • Predict when == seems to work on Strings (two identical literals) and when it fails (text read from input)
  • Replace a reference comparison with equals() and keep == where it is right: on a primitive char
  • Name the three Java classes for text data: Character, String and StringBuilder

How to complete it

  1. Open the lab page (7.1.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (CrewGate.java).
