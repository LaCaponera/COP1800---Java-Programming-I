Lab 7.2: The badge printer that rejects Muñoz

Character class methods: is... methods that test a char and to... methods that convert it

Estimated time: about 25 minutes. Reading: Ch. 7, section 7.2 (pp. 238–241).

You will be able to:

  • Use Character.isLetter(), isDigit() and isWhitespace() to test a char instead of hand-written ranges
  • Use Character.toUpperCase() to convert a char, knowing it leaves non-letters unchanged
  • Distinguish the is methods (return a boolean) from the to methods (return a converted char)
  • Explain why the methods are called with the class name: they are static

How to complete it

  1. Open the lab page (7.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (BadgePrinter.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; each method has one clear return per case; no leftover range tests or magic numbers.

The checks on the lab page give you feedback; they are not your grade.
