Lab 7.5: The departure board that rebuilds itself every hour

StringBuilder: append(), insert(), setLength(), capacity, and comparing contents with toString()

Estimated time: about 30 minutes. Reading: Ch. 7, section 7.5 (pp. 253–257).

You will be able to:

  • Explain why building text with + in a loop creates a new String on every pass
  • Build text in a loop with a StringBuilder created with new and an initial capacity
  • Change a StringBuilder with append(), insert() and setLength(), then turn it into a String with toString()
  • Explain why equals() on two StringBuilder objects compares references, and compare their contents instead

How to complete it

  1. Open the lab page (7.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (DockBoard.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the builder has a clear name; String is kept where text is built once and StringBuilder is used where it changes repeatedly.

The checks on the lab page give you feedback; they are not your grade.
