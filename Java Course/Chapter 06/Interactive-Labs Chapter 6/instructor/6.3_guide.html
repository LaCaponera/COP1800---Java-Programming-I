COP1800 · Java Programming I · Lab 6.3

The fish market's ticket that starts at 2

Objectives

  • Use the add and assign operator += to accumulate a total
  • Use ++ as a stand-alone statement to count events
  • Explain the value a prefix ++x and a postfix x++ produce inside a larger expression
  • Explain why count = count++; leaves count unchanged

Requirements

  1. R1 takeTicket() returns the current value of nextTicket and then increases it by 1, using the postfix increment operator. The first ticket of the day is 1.
  2. R2 recordSale() increases salesCount by exactly 1 with a stand-alone increment statement (salesCount++;, ++salesCount; or salesCount += 1;).
  3. R3 recordSale() accumulates the kilos with the add and assign operator: totalKg += kg;.
  4. R4 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. nextTicket starts at 1. What number does the starter's takeTicket() return the first time it is called, and why?

    1. The prefix ++ increases nextTicket to 2 first and then produces the new value, 2, which is returned.

  2. salesCount is 0. Predict its value after salesCount = salesCount++; runs once.

    Still 0. salesCount++ produces the old value 0, salesCount becomes 1, then the assignment stores 0 back into it.

Solution

FishMarketCounter.java
public class FishMarketCounter
{
    private int nextTicket = 1;
    private int salesCount = 0;
    private double totalKg = 0.0;

    // Hands out a ticket and gets the dispenser ready for the next customer.
    public int takeTicket()
    {
        return nextTicket++;
    }

    // Records one sale on the scale.
    public void recordSale(double kg)
    {
        salesCount++;
        totalKg += kg;
    }

    public void printSummary()
    {
        System.out.println("Sales: " + salesCount + ", total " + totalKg + " kg");
    }

    public static void main(String[] args)
    {
        FishMarketCounter counter = new FishMarketCounter();
        System.out.println("Now serving " + counter.takeTicket());
        counter.recordSale(1.5);
        System.out.println("Now serving " + counter.takeTicket());
        counter.recordSale(0.75);
        counter.printSummary();
    }
}

Walkthrough

Prefix vs postfix in an expression. ++nextTicket increases the variable and then produces the new value, so the first ticket was 2. nextTicket++ produces the old value and then increases the variable, so the customer gets 1 and the dispenser is ready with 2: exactly what a ticket dispenser does. The book's rule: a prefix operator returns the value after the calculation, a postfix operator the value before it (b = 4; c = b++; leaves c at 4 and b at 5).

**salesCount = salesCount++;** is evaluated in three steps: the postfix expression produces the old value 0; salesCount is increased to 1; then the assignment stores the expression's value, 0, back into salesCount. The increment is overwritten every time. On its own line, salesCount++;, ++salesCount; and salesCount += 1; are identical because nobody uses the expression's value.

Accumulating. totalKg += kg; means totalKg = totalKg + kg;: the add and assign operator adds and assigns in one step. The starter's line already worked; the shortcut is a convenience that makes the intent ("add to the running total") obvious, and it pairs with -=, *=, /= and %=.

Messages students see when a check fails

C1 · takeTicket() returns the value before the increment

Use the postfix form: return nextTicket++;. The postfix expression produces the current number (1 for the first customer) and only then moves the dispenser to the next one. The prefix form ++nextTicket produces the new value, which skipped ticket 1.

Hint:

Which form returns the value before the calculation?

C2 · salesCount is increased by a stand-alone statement

Replace salesCount = salesCount++; with salesCount++;. In the starter, the postfix expression produces the old value, the variable is increased, and then the assignment stores the old value back, so the count never moves.

C3 · The kilos are accumulated with +=

Write totalKg += kg;. The add and assign operator adds kg to the running total and stores the result in one step; that is the shortcut this section introduces for accumulating.

Progressive hints

  1. Write down what each expression produces and what the variable holds afterwards: ++nextTicket when nextTicket is 1, and nextTicket++ when it is 1.

  2. For salesCount = salesCount++;, do the three steps in order: evaluate the right side, apply the increment, then assign. Which value is assigned last?

  3. When the result of ++ isn't used in a larger expression, prefix and postfix behave the same; the problem only appears when the value is returned or assigned.

Reflection: questions and model answers

  1. Explain in your own words, step by step, why salesCount = salesCount++; loses the increment.

    The right side is evaluated first: the postfix expression's value is the old count, and as a side effect the variable is increased. Then the assignment runs last and overwrites the variable with that old value, so the increase is lost.

  2. If d is 5, what is 2 * ++d? What is 2 * d++? What does d hold after each?

    2 * ++d is 12 (d becomes 6 first). 2 * d++ is 10 (the old value 5 is used). In both cases d holds 6 afterwards.

  3. In recordSale(), would ++salesCount; work as well as salesCount++;? When does the choice between prefix and postfix matter?

    Yes. On its own line the value of the expression isn't used, so both just add 1. The choice matters only when the expression is part of something larger: returned, assigned, compared or used in arithmetic.
