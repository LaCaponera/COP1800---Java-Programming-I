COP1800 · Java Programming I · Lab 6.1

The harbor pump that stops after one stroke

Objectives

  • Describe the loop structure: a Boolean expression is evaluated, the body runs while it is true, and the expression is evaluated again after every iteration
  • Explain the difference between a decision, which asks its question once, and a loop, which asks it again after each pass
  • Count iterations with a counter that starts at 0 before the loop
  • Show with output that a loop body can run zero times, and that it does not run one last time when the test becomes false

Requirements

  1. R1 Replace the if with a while loop that tests the same Boolean expression, levelCm > SAFE_LEVEL, so the pump cycles until the water is at or below the safe level.
  2. R2 Count the iterations: cycles starts at 0 before the loop, increases by 1 in the loop body, numbers each cycle line, and appears in the stopped at ... after N cycle(s) line printed after the loop.
  3. R3 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. With the starter, how many times does the body under if(levelCm > SAFE_LEVEL) run for the North dock (130 cm), and what level does it report?

    Once. It lowers the water to 110 cm and stops, even though 110 is still above 80, because an if never asks its question a second time.

  2. In a loop, what happens immediately after the last statement of the body runs?

    Control goes back to the top and the Boolean expression is evaluated again. If it is still true, the body runs again; if it is false, the loop ends.

Solution

PumpStation.java
public class PumpStation
{
    public static final int SAFE_LEVEL = 80;   // cm of water the pit can hold safely
    public static final int PUMP_CM = 20;      // one pump cycle lowers the water this much

    public static void drain(String dock, int levelCm)
    {
        System.out.println(dock + " dock: water at " + levelCm + " cm");
        int cycles = 0;

        while(levelCm > SAFE_LEVEL)
        {
            levelCm = levelCm - PUMP_CM;
            cycles = cycles + 1;
            System.out.println("  cycle " + cycles + ": water now " + levelCm + " cm");
        }

        System.out.println("  stopped at " + levelCm + " cm after " + cycles + " cycle(s)");
    }

    public static void main(String[] args)
    {
        drain("North", 130);
        drain("East", 60);
    }
}

Walkthrough

An if evaluates its Boolean expression once: true or false, the program moves on. A while evaluates the same expression, runs the body if it is true, and then evaluates it again. Each pass is one iteration. For the North dock the test is true at 130, 110 and 90 cm and false at 70 cm, so there are three iterations and no fourth: when the test is false the loop ends immediately (the false statement in the book's Two Truths & a Lie for 6.1). The East dock shows the other edge: 60 is not above 80, so the body runs zero times and cycles stays 0. The counter has to start at 0 before the loop (inside it, it would be reset every pass) and be reported after the closing brace, where the final value is known. levelCm = levelCm - PUMP_CM is what makes the test eventually false; section 6.2 names this the loop control variable.

Messages students see when a check fails

C1 · A while loop tests levelCm > SAFE_LEVEL

Change if(levelCm > SAFE_LEVEL) to while(levelCm > SAFE_LEVEL) and keep the braces. A decision asks its question once; a loop asks it again after every pass, so the pump keeps cycling until the water is safe.

Hint:

Same question, different keyword.

C2 · cycles goes up by 1 inside the loop body

Add 1 to cycles inside the loop's braces (for example cycles = cycles + 1;). Each pass through the body is one iteration, so that is the only place where counting it is correct.

C3 · The counter starts at 0 before the loop and is reported after it

Keep int cycles = 0; above the loop and print cycles in the stopped at line after the loop's closing brace. Declared inside the loop, the count would restart every pass; printed inside it, you would get a summary after every cycle.

Progressive hints

  1. An if asks its question once. Which Java structure asks the same question again after every pass through its body?

  2. Keep the Boolean expression exactly as it is; only the keyword changes. Then decide which line marks "one more pass".

  3. The cycle number belongs in the line printed inside the loop; the total belongs in the line printed after the closing brace.

Reflection: questions and model answers

  1. When the North dock reaches 70 cm, levelCm > SAFE_LEVEL is false. Does the loop body run one last time? Use your output as evidence.

    No. The log stops at cycle 3 (70 cm); there is no cycle 4. When the test is false the loop ends at once and the next statement after the closing brace runs.

  2. The East dock printed 0 cycles. What does that tell you about where a while loop's test is evaluated relative to its body?

    The test is evaluated before the body ever runs. If it is false the first time, the body is skipped completely, so a while loop can execute zero times.

  3. Suppose a technician set PUMP_CM to 0. What would drain("North", 130) do, and why?

    It would loop forever. levelCm would never change, so levelCm > SAFE_LEVEL would stay true and the program would keep printing cycle lines. Something in the body must move the test toward false.

Extension

The harbor wants an alarm: when a pit needs more than 5 cycles, print ALARM: check the pump once, after pumping stops. Write the if for it. Why does it belong after the loop rather than inside it? Test it with drain("Dry dock", 250).
