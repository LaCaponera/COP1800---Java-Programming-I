The timetable with no last ferry

Objectives

  • Write a for loop whose header initializes, tests and updates the loop control variable
  • Convert a counter-controlled while loop into an equivalent for loop
  • Choose the relational operator that includes or excludes the final value
  • Explain why altering the loop control variable inside a for loop's body skips iterations

Requirements

  1. R1 printDepartures() uses one for loop and no while. Its header initializes time to first, tests it, and updates it with INTERVAL (time += INTERVAL).
  2. R2 The test includes a ferry that leaves exactly at last, so 9:00 appears on the 6:00–9:00 board.
  3. R3 boardingCountdown() calls every number from from down to 1: the loop control variable s is changed only in the for header, never in the body.
  4. R4 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. Trace the starter's boardingCountdown(5). Which numbers does it print, and why?

    5 3 1. Each iteration decreases s twice, once with s = s - 1 in the body and once with --s in the header.

  2. In the starter's printDepartures(360, 540), is the 9:00 ferry (540) printed? Explain using the loop's test.

    No. After 8:15, time becomes 540, and 540 < 540 is false, so the loop ends before printing it.

Solution

FerrySchedule.java
public class FerrySchedule
{
    public static final int INTERVAL = 45;   // minutes between departures

    // Given: turns minutes after midnight into a clock time, e.g. 405 -> "6:45".
    public static String clock(int minutes)
    {
        int hours = minutes / 60;
        int mins = minutes % 60;
        if(mins < 10)
            return hours + ":0" + mins;
        else
            return hours + ":" + mins;
    }

    public static void printDepartures(int first, int last)
    {
        for(int time = first; time <= last; time += INTERVAL)
        {
            System.out.print(clock(time) + " ");
        }
        System.out.println();
    }

    public static void boardingCountdown(int from)
    {
        for(int s = from; s >= 1; --s)
        {
            System.out.print(s + " ");
        }
        System.out.println("Gangway up");
    }

    public static void main(String[] args)
    {
        printDepartures(360, 540);   // 6:00 to 9:00
        boardingCountdown(5);
    }
}

Walkthrough

A for header holds the three actions a while loop spreads over three places: int time = first runs once, time <= last is tested before every iteration, and time += INTERVAL runs after every body. Declaring time in the header limits its scope to the loop, which is all it is needed for. The missing 9:00 ferry came from <: when time reaches 540, 540 < 540 is false, so the last sailing was never printed; <= includes it. The countdown skipped numbers because s was changed twice per iteration: once by s = s - 1 in the body and once by --s in the header, so it went 5, 3, 1. The book advises using the same variable in all three header sections and not altering it in the body; once the header updates it, the body only uses it. Like a while, a for is a pretest loop: printDepartures(600, 590) prints an empty line because the test is false before the first iteration.

Messages students see when a check fails

C1 · One for loop drives the timetable

Write the timetable as for(int time = first; ...; time += INTERVAL) and remove the while. The header puts the start, the test and the step in one place, so a reader sees the whole count at a glance.

Hint:

The three statements that controlled the while loop each move into one section of the for header.

C2 · The last sailing is included

Test time <= last. With <, a ferry that leaves exactly at last makes the test false (540 < 540), so the 9:00 departure never prints.

C3 · The countdown changes s only in its header

Delete s = s - 1; from the countdown's body and keep --s in the header. The header already moves s down by one after each body, so changing it in the body as well skips every other number.

Progressive hints

  1. Find the three lines that initialize, test and change time in the while version. Each one has a place inside the for header's parentheses.

  2. Trace the last sailing: when time is 540 and last is 540, is your test true or false?

  3. In the countdown, count how many times s decreases during one iteration.

Reflection: questions and model answers

  1. Name the three sections of your for header in printDepartures() and say when each one runs.

    int time = first runs once, before anything else. time <= last is tested before every iteration, including the first. time += INTERVAL runs after each execution of the body, then the test is evaluated again.

  2. How many times does the body run for printDepartures(600, 590)? What does that tell you about for loops?

    Zero times: 600 <= 590 is false at the start. A for loop, like a while loop, is a pretest loop; its body might never execute.

  3. You declared time inside the for header. Could a statement after the loop print time? Why might that be a good thing?

    No. A variable declared in the header goes out of scope when the loop ends. That's good when it's only a counter: nothing else can misuse it, and the name can be reused for another loop.

Extension

Add printReturnTrips(int first, int last) that lists the same sailings from the latest to the earliest, with a for loop that decreases its control variable. Then try a header with two variables, for(int time = first, trip = 1; time <= last; time += INTERVAL, ++trip), to print Trip 1 6:00, Trip 2 6:45, and so on.
