Lab 6.1: The harbor pump that stops after one stroke

The loop structure: test, body, test again, and the iteration that never comes

Estimated time: about 20 minutes. Reading: Ch. 6, section 6.1 (pp. 201–202).

You will be able to:

  • Describe the loop structure: a Boolean expression is evaluated, the body runs while it is true, and the expression is evaluated again after every iteration
  • Explain the difference between a decision, which asks its question once, and a loop, which asks it again after each pass
  • Count iterations with a counter that starts at 0 before the loop
  • Show with output that a loop body can run zero times, and that it does not run one last time when the test becomes false

How to complete it

  1. Open the lab page (6.1.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (PumpStation.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; every loop body in braces and indented under its loop header; named constants instead of bare numbers in loop conditions.

The checks on the lab page give you feedback; they are not your grade.
