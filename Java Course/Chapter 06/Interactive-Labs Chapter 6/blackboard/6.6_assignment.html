Lab 6.6: The boatyard's empty docks and nine paint changes

Nested loops: resetting the inner loop, and choosing which loop goes outside

Estimated time: about 30 minutes. Reading: Ch. 6, section 6.6 (pp. 220–223).

You will be able to:

  • Write a nested loop in which the inner loop is entirely contained in the outer loop and restarts for every outer iteration
  • Trace how many times an inner loop body runs: outer iterations times inner iterations
  • Decide which variable should control the outer loop: the one that should change least often
  • Explain why two nestings can do the same work in a different, and differently costly, order

How to complete it

  1. Open the lab page (6.6.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (Boatyard.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; every loop body in braces and indented under its loop header; named constants instead of bare numbers in loop conditions.

The checks on the lab page give you feedback; they are not your grade.
