Lab 6.5: The parking kiosk that never shows its menu

do…while: a posttest loop for work that must happen at least once

Estimated time: about 20 minutes. Reading: Ch. 6, section 6.5 (pp. 217–219).

You will be able to:

  • Distinguish pretest loops (while, for) from the posttest do…while loop
  • Write a do…while loop with a braced body and the test at the bottom, ending in a semicolon
  • Recognize when a fake starting value is a sign that the loop's test is in the wrong place
  • Explain why the compiler accepts a variable declared without a value when a do…while body assigns it

How to complete it

  1. Open the lab page (6.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ParkingKiosk.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the do…while body in braces with } while(...); on one line; named constants instead of bare numbers in the menu tests.

The checks on the lab page give you feedback; they are not your grade.
