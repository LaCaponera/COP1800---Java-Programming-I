COP1800 · Java Programming I · Lab 14.4

The pay station that shows only the price

Objectives

  • Explain why components added to a JFrame with its default BorderLayout hide each other
  • Install a layout manager with setLayout()
  • Choose a FlowLayout alignment with FlowLayout.LEFT, RIGHT or CENTER

Requirements

  1. R1 build() installs a FlowLayout on the screen with setLayout(), so all three labels are visible.
  2. R2 The flow layout places components starting at the left edge of each row (FlowLayout.LEFT).
  3. R3 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. The starter creates a FlowLayout named flow. Why do the labels still pile up on top of each other?

    flow is never passed to setLayout(), so the frame still uses its default BorderLayout and every label goes into the same region.

  2. With the starter's BorderLayout, which of the three labels can a driver read, and why that one?

    Rate: $2 per hour, the last one added. Each label added without a region is placed in the same region, on top of the earlier ones.

Solution

PayStationScreen.java
import javax.swing.*;
import java.awt.*;

public class PayStationScreen
{
    static final int SCREEN_WIDTH = 420;
    static final int SCREEN_HEIGHT = 160;

    public static JFrame build(int level, int freeSpaces)
    {
        JFrame screen = new JFrame("Garage pay station");
        screen.setSize(SCREEN_WIDTH, SCREEN_HEIGHT);
        screen.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

        FlowLayout flow = new FlowLayout(FlowLayout.LEFT);
        screen.setLayout(flow);

        screen.add(new JLabel("Level " + level));
        screen.add(new JLabel("Spaces free: " + freeSpaces));
        screen.add(new JLabel("Rate: $2 per hour"));
        return screen;
    }

    public static void main(String[] args)
    {
        JFrame screen = build(2, 37);
        screen.setVisible(true);
    }
}

Walkthrough

With the default BorderLayout and no region given, every label goes into the same region and the last one added covers the others (p. 555); the test shows that only one label gets any room. Creating new FlowLayout() builds a layout manager object, but the frame keeps using its border layout until screen.setLayout(flow) installs it. new FlowLayout(FlowLayout.LEFT) starts each row at the left edge instead of the default center (p. 555), so the lines line up like a list. The compact form screen.setLayout(new FlowLayout(FlowLayout.LEFT)); from p. 556 also passes, as does FlowLayout.LEADING, which means left in left-to-right languages.

Test program

Students run it in an IDE and paste the output into the page.

TestPayStationScreen.java
import javax.swing.*;
import java.awt.*;

public class TestPayStationScreen
{
    public static void main(String[] args)
    {
        JFrame screen = PayStationScreen.build(2, 37);
        screen.addNotify();   // lay the window out without showing it
        screen.validate();

        Container content = screen.getContentPane();
        LayoutManager layout = content.getLayout();
        if (layout instanceof FlowLayout)
            System.out.println("Layout: FlowLayout, aligned "
                + alignment((FlowLayout) layout));
        else if (layout instanceof BorderLayout)
            System.out.println("Layout: BorderLayout");
        else
            System.out.println("Layout: " + layout.getClass().getSimpleName());

        System.out.println("Labels added: " + content.getComponentCount());
        int shown = 0;
        for (Component part : content.getComponents())
        {
            if (part.getWidth() > 0)
            {
                System.out.println("  showing: " + ((JLabel) part).getText());
                ++shown;
            }
        }
        System.out.println("Labels with room on screen: " + shown);
        System.exit(0);   // close the window
    }

    static String alignment(FlowLayout flow)
    {
        int value = flow.getAlignment();
        if (value == FlowLayout.LEFT)
            return "LEFT";
        if (value == FlowLayout.RIGHT)
            return "RIGHT";
        if (value == FlowLayout.CENTER)
            return "CENTER";
        if (value == FlowLayout.LEADING)
            return "LEFT";
        return "TRAILING";
    }
}

Messages students see when a check fails

C1 · The screen installs a layout manager

Call screen.setLayout(flow);. Creating a layout manager doesn't attach it to the frame; until you install it, the frame keeps its BorderLayout.

C2 · Rows start at the left edge

Create the layout with new FlowLayout(FlowLayout.LEFT). Without an argument, FlowLayout centers each row.

Progressive hints

  1. Creating a layout manager does nothing by itself: the frame has to be told to use it.

  2. FlowLayout has a constructor that takes one of three constants defined in the FlowLayout class.

  3. Section 14.4 installs a layout with aFrame.setLayout(flow);. Your frame is called screen.

Reflection: questions and model answers

  1. What is the difference between creating a layout manager and installing it? Point to the line of your code that does each.

    new FlowLayout(FlowLayout.LEFT) creates the object; screen.setLayout(flow) installs it on the frame. Only after installing does the frame use it to place components.

  2. Suppose the garage's screen were only 150 pixels wide. What would FlowLayout do with the three labels, and would a driver lose any of them?

    When a row is full, the next components spill into a new row, so the labels would stack on separate rows. None would be hidden as long as the window is tall enough.

Extension
