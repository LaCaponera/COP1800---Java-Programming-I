Lab 14.9: The burrito builder that lets you pick three proteins

Use a JComboBox, a ButtonGroup and JCheckBoxes, and price the order from what is selected

Estimated time: about 30 minutes. Reading: Ch. 14, section 14.9 (pp. 572–580).

You will be able to:

  • Build a JComboBox<String> from an array and look up a price with getSelectedIndex() and a parallel array
  • Group JCheckBoxes in a ButtonGroup so only one can be selected, and leave independent options ungrouped
  • Respond to ItemEvents by recalculating from the components' current state with isSelected()

How to complete it

  1. Open the lab page (14.9.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (BurritoFrame.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; prices only in the named constants and the parallel array; one method computes the total.

The checks on the lab page give you feedback; they are not your grade.
