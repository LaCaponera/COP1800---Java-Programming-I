Lab 14.6: The renewal form with a field too small for a barcode

Add a JTextField and a JButton, then read, clear and lock the field

Estimated time: about 30 minutes. Reading: Ch. 14, section 14.6 (pp. 559–563).

You will be able to:

  • Add JLabel, JTextField and JButton components to a JFrame in the order users read them
  • Size a JTextField for the data it will hold
  • Use getText(), setText() and setEditable() on text fields and buttons

How to complete it

  1. Open the lab page (14.6.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (RenewalFrame.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; named constants (LIMIT, READY) used instead of repeated literals; components added in reading order.

The checks on the lab page give you feedback; they are not your grade.
