Lab 14.2: The bus-times window nobody can read

Create JFrames with a title and size, and decide what the Close button does

Estimated time: about 25 minutes. Reading: Ch. 14, section 14.2 (pp. 547–551).

You will be able to:

  • Construct a JFrame with a title and set its size with named constants
  • Use setResizable() and setVisible() deliberately
  • Choose between EXIT_ON_CLOSE and DISPOSE_ON_CLOSE for each window of a program

How to complete it

  1. Open the lab page (14.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (KioskWindows.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; sizes in named constants; each method only builds its window.

The checks on the lab page give you feedback; they are not your grade.
