Lab 14.5: Three desk windows, and a constructor that builds a stranger

Extend JFrame and configure this frame in its own constructor

Estimated time: about 25 minutes. Reading: Ch. 14, section 14.5 (pp. 557–558).

You will be able to:

  • Create a child class of JFrame whose constructor sets the frame's title, size, position and close operation
  • Call the parent constructor with super() and use methods with an implied this
  • Use setBounds() and close operations so several frames of one class can share a screen

How to complete it

  1. Open the lab page (14.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (DeskFrame.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; no leftover local JFrame; constants used for every size and position.

The checks on the lab page give you feedback; they are not your grade.
