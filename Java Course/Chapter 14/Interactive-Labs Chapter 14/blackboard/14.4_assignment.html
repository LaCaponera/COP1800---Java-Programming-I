Lab 14.4: The pay station that shows only the price

Install a FlowLayout so every component in a JFrame is visible

Estimated time: about 20 minutes. Reading: Ch. 14, section 14.4 (pp. 555–556).

You will be able to:

  • Explain why components added to a JFrame with its default BorderLayout hide each other
  • Install a layout manager with setLayout()
  • Choose a FlowLayout alignment with FlowLayout.LEFT, RIGHT or CENTER

How to complete it

  1. Open the lab page (14.4.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (PayStationScreen.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; the layout created once and installed with setLayout(); no unused variables.

The checks on the lab page give you feedback; they are not your grade.
