Lab 14.8: The 5K sign-up form that ignores half of what runners do

Implement several listener interfaces and register each one on the right source

Estimated time: about 30 minutes. Reading: Ch. 14, section 14.8 (pp. 569–571).

You will be able to:

  • Implement more than one listener interface in a single class
  • Match each component to its listener-registering method (Table 14-3)
  • Write event handlers with the exact names Java calls (Table 14-4), including every method an interface declares

How to complete it

  1. Open the lab page (14.8.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (RaceSignupFrame.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; @Override on each handler; one registering call per source.

The checks on the lab page give you feedback; they are not your grade.
