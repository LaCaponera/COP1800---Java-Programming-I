Lab 14.7: The loyalty card whose buttons do nothing

Register a JFrame as a listener, tell event sources apart and disable buttons

Estimated time: about 30 minutes. Reading: Ch. 14, section 14.7 (pp. 563–569).

You will be able to:

  • Name the source and the listener of an event in an event-driven program
  • Register a frame as the listener for several components with addActionListener(this)
  • Use getSource() in actionPerformed() to respond differently to each source, and setEnabled() to switch buttons on and off

How to complete it

  1. Open the lab page (14.7.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (StampCardFrame.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; one actionPerformed() with a clear branch per source; button states set in one place.

The checks on the lab page give you feedback; they are not your grade.
