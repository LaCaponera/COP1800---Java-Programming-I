Lab 14.3: The pickup board that never shows the order

Change a JLabel's text and font, and remove it from a window correctly

Estimated time: about 25 minutes. Reading: Ch. 14, section 14.3 (pp. 552–554).

You will be able to:

  • Change the text of an existing JLabel with setText() instead of creating a new label
  • Build Font objects and derive one font from another with deriveFont()
  • Remove a component from a container and refresh it with invalidate(), validate() and repaint()

How to complete it

  1. Open the lab page (14.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (OrderBoard.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; the shared HEADLINE_FONT constant reused; no unused labels or fonts left behind.

The checks on the lab page give you feedback; they are not your grade.
