Lab 10.2: The thermostat log that gave up after one typo

try, catch, and clearing the bad entry

Estimated time: about 25 minutes. Reading: Ch. 10, section 10.2 (pp. 397–404).

You will be able to:

  • Place a statement that might fail in a try block and handle the failure in a catch block
  • Use the catch block to repair the data so the program continues with a valid value
  • Clear the rest of a bad input line with nextLine() so later entries can still be read

How to complete it

  1. Open the lab page (10.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ReadingLog.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; the try block holds only the risky statement; the line-clearing call sits after the try...catch pair.

The checks on the lab page give you feedback; they are not your grade.
