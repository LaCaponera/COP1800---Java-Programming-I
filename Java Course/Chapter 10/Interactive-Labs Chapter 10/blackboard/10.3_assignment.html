Lab 10.3: The bill splitter that won't compile

Several catch blocks, the smallest basket first

Estimated time: about 25 minutes. Reading: Ch. 10, section 10.3 (pp. 404–408).

You will be able to:

  • Follow one try block with several catch blocks, each with its own response
  • Order catch blocks from specific to general so none of them is unreachable
  • Explain why only the first failing statement in a try block throws

How to complete it

  1. Open the lab page (10.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (BillSplitter.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; catch blocks ordered from specific to general; each message matches its cause.

The checks on the lab page give you feedback; they are not your grade.
