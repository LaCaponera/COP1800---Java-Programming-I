Lab 10.7: The playlist import that died three methods deep

Follow the exception up the call stack, then catch it where you can decide

Estimated time: about 25 minutes. Reading: Ch. 10, section 10.7 (pp. 415–418).

You will be able to:

  • Read a stack trace from the method that threw back to main()
  • Explain how an uncaught exception travels up the call stack to the calling method
  • Choose the method where catching an exception makes sense, and leave the others alone

How to complete it

  1. Open the lab page (10.7.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (Playlist.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; the try block sits inside the loop; the helper methods are unchanged.

The checks on the lab page give you feedback; they are not your grade.
