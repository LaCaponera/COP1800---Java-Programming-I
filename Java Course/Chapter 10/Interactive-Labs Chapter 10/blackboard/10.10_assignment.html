Lab 10.10: The check-in kiosk that wouldn't compile on a Mac

Calling a library method that throws: Runtime.exec() and IOException

Estimated time: about 20 minutes. Reading: Ch. 10, section 10.10 (pp. 430–432).

You will be able to:

  • Call a method written by others that throws a checked IOException
  • Decide between catching the exception and adding throws IOException to a header
  • Keep a program running, at a reduced level, when an optional tool can't start

How to complete it

  1. Open the lab page (10.10.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (KeyboardLauncher.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; openTool() has one try block, one catch block and a return value on each path.

The checks on the lab page give you feedback; they are not your grade.
