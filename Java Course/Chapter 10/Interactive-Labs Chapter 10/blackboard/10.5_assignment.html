Lab 10.5: The group order that reported the wrong mistake

Business as usual in one place, the exceptions out of the way

Estimated time: about 25 minutes. Reading: Ch. 10, section 10.5 (pp. 410–412).

You will be able to:

  • Rewrite nested error-checking if statements as one try block followed by catch blocks
  • Explain how grouping the normal steps together makes logic easier to follow and harder to get wrong
  • Use methods that throw exceptions without handling them, and decide how the caller responds

How to complete it

  1. Open the lab page (10.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (OrderDesk.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; the try block reads as the normal path; one catch block per exception type with the matching message.

The checks on the lab page give you feedback; they are not your grade.
