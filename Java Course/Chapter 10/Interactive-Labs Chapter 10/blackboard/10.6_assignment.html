Lab 10.6: The greenhouse dashboard that won't compile

Checked exceptions: catch it, or say so in the header

Estimated time: about 25 minutes. Reading: Ch. 10, section 10.6 (pp. 412–415).

You will be able to:

  • Tell checked exceptions from unchecked ones and apply the catch-or-specify requirement
  • Declare an exception with a throws clause when the caller should decide what to do
  • Choose, method by method, whether to catch an exception or pass it on

How to complete it

  1. Open the lab page (10.6.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (Greenhouse.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; one method catches, the other declares; the specific IOException type is used throughout.

The checks on the lab page give you feedback; they are not your grade.
