Lab 10.9: The night bus that left at 00:0-15

State what must be true with assert, then fix the logic

Estimated time: about 25 minutes. Reading: Ch. 10, section 10.9 (pp. 421–424).

You will be able to:

  • Tell a logic error that produces wrong output from one that stops the program
  • Write an assert statement with a Boolean expression and an error message
  • Use an assertion's message to find and fix a negative-remainder bug

How to complete it

  1. Open the lab page (10.9.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ShiftClock.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces kept; the assertion follows the calculation it checks and its message includes the values.

The checks on the lab page give you feedback; they are not your grade.
