Lab 9.12: The e-bike that couldn't be rented

A class has one superclass but can implement any number of interfaces

Estimated time: about 30 minutes. Reading: Ch. 9, section 9.12 (pp. 371–377).

You will be able to:

  • Explain why Java doesn't allow a class to extend two classes
  • Write an interface with abstract methods and a constant, and implement it with implements
  • Write a class header that both extends a class and implements an interface

How to complete it

  1. Open the lab page (9.12.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Rentable.java, Kayak.java, ElectricBike.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; @Override on implemented methods; extends written before implements.

The checks on the lab page give you feedback; they are not your grade.
