Lab 9.1: The audiobook that never got the label fix

An AudioBook “is a” Book; a Library “has” books

Estimated time: about 20 minutes. Reading: Ch. 9, section 9.1 (pp. 329–332).

You will be able to:

  • Use the “is a” test to decide which class should inherit from which
  • Tell inheritance (is-a) apart from containment (has-a)
  • Explain how reusing a tested parent class reduces errors

How to complete it

  1. Open the lab page (9.1.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (AudioBook.java, Library.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; no leftover copied members in AudioBook; clear field name in Library.

The checks on the lab page give you feedback; they are not your grade.
