Lab 9.4: The hotel suites that won't compile

When the parent needs arguments, the child's constructor must call super() first

Estimated time: about 25 minutes. Reading: Ch. 9, section 9.4 (pp. 339–343).

You will be able to:

  • Predict the order in which parent and child constructors run
  • Call a parent constructor that requires arguments with super(...) as the first statement
  • Write a child constructor that passes a constant to its parent

How to complete it

  1. Open the lab page (9.4.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Suite.java, StaffRoom.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; super(...) is the first statement; no fields duplicated from Room.

The checks on the lab page give you feedback; they are not your grade.
