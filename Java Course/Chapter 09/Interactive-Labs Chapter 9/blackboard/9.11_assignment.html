Lab 9.11: The conference that printed two badges for Priya

Override toString(), equals(Object) and hashCode() from the Object class

Estimated time: about 30 minutes. Reading: Ch. 9, section 9.11 (pp. 364–370).

You will be able to:

  • Override toString() so an object prints useful information
  • Tell an overloaded equals(Attendee) apart from an overriding equals(Object), and write the override safely
  • Override hashCode() so equal objects have equal hash codes

How to complete it

  1. Open the lab page (9.11.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (Attendee.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; @Override on all three methods; no cast before the null and class checks.

The checks on the lab page give you feedback; they are not your grade.
