COP1800 · Java Programming I · Lab 8.7

The race results that give Dev's time to Ana

Objectives

  • Swap two array elements with a temporary variable
  • Trace a bubble sort and explain why each pass can make one comparison fewer
  • Sort an array of objects by one field while swapping the objects as units

Requirements

  1. R1 When two runners are out of order, sortByTime() swaps the two Runner objects using a temporary Runner variable; it no longer calls setSeconds().
  2. R2 Each pass compares one pair fewer than the pass before, because the slowest remaining runner is already at the end: 10 comparisons for 5 runners.
  3. R3 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. Why does a swap need a third variable? What would runners[b] = runners[b + 1]; runners[b + 1] = runners[b]; do?

    The first assignment overwrites runners[b], so its old value is lost. Both elements would end up referring to the same runner, the one from b + 1. A temporary variable keeps the first value while the second is copied.

  2. After the first pass of a bubble sort over these 5 runners, which runner is certain to be in the final place, and where?

    The slowest runner, Cleo, is in the last element, runners[4], because every comparison carried the larger time one place further down.

Leaderboard.java
public class Leaderboard
{
    // How many pairs the last sortByTime() call compared.
    public static int comparisons = 0;

    // Sorts the runners from fastest (fewest seconds) to slowest.
    public static void sortByTime(Runner[] runners)
    {
        comparisons = 0;
        for(int a = 0; a < runners.length - 1; ++a)
        {
            // TODO (R2): after each pass, the slowest runner left has sunk
            // to the end. Stop comparing pairs that are already in place.
            for(int b = 0; b < runners.length - 1; ++b)
            {
                ++comparisons;
                if(runners[b].getSeconds() > runners[b + 1].getSeconds())
                {
                    // TODO (R1): this swaps the times and leaves the names
                    // behind. Swap the two Runner objects instead.
                    int temp = runners[b].getSeconds();
                    runners[b].setSeconds(runners[b + 1].getSeconds());
                    runners[b + 1].setSeconds(temp);
                }
            }
        }
    }

    public static String board(Runner[] runners)
    {
        String text = "";
        for(int x = 0; x < runners.length; ++x)
        {
            int min = runners[x].getSeconds() / 60;
            int sec = runners[x].getSeconds() % 60;
            text += (x + 1) + ". " + runners[x].getName() + " "
                + min + ":" + (sec < 10 ? "0" : "") + sec + "\n";
        }
        return text;
    }
}

Solution

Leaderboard.java
public class Leaderboard
{
    // How many pairs the last sortByTime() call compared.
    public static int comparisons = 0;

    // Sorts the runners from fastest (fewest seconds) to slowest.
    public static void sortByTime(Runner[] runners)
    {
        comparisons = 0;
        for(int a = 0; a < runners.length - 1; ++a)
        {
            for(int b = 0; b < runners.length - 1 - a; ++b)
            {
                ++comparisons;
                if(runners[b].getSeconds() > runners[b + 1].getSeconds())
                {
                    Runner temp = runners[b];
                    runners[b] = runners[b + 1];
                    runners[b + 1] = temp;
                }
            }
        }
    }

    public static String board(Runner[] runners)
    {
        String text = "";
        for(int x = 0; x < runners.length; ++x)
        {
            int min = runners[x].getSeconds() / 60;
            int sec = runners[x].getSeconds() % 60;
            text += (x + 1) + ". " + runners[x].getName() + " "
                + min + ":" + (sec < 10 ? "0" : "") + sec + "\n";
        }
        return text;
    }
}

Walkthrough

Swapping two values needs a temporary variable: copy one, overwrite it with the other, then put the copy in the second place (pp. 292–293). A bubble sort repeatedly compares neighbours and swaps the pairs that are out of order, so the largest remaining value sinks to the end on every pass (pp. 293–294). Because the last a elements are in their final places after a passes, the inner limit can shrink by one each pass; Figure 8-22 does this with a comparisonsToMake variable that decreases after each pass, and runners.length - 1 - a is the same idea: 4 + 3 + 2 + 1 = 10 comparisons instead of 4 × 4 = 16. When sorting objects, you compare one field but swap the whole object (pp. 295–296): the temporary variable has type Runner, and the swap moves references, so each name travels with its own time. The starter's setSeconds() swap changed the data inside the objects and attached the times to the wrong people.

Messages students see when a check fails

C1 · The swap moves whole Runner objects

Swap the elements themselves through a Runner temporary: Runner temp = runners[b];, then copy runners[b + 1] into runners[b], and temp into runners[b + 1]. Swapping only the seconds leaves every name where it was.

C2 · Each pass makes one comparison fewer

Shorten the inner loop on each pass, for example b < runners.length - 1 - a. After pass a, the last a runners are already in their final places, so comparing them again only wastes work.

Progressive hints

  1. The temporary variable must be able to hold what is in an array element. The elements of runners are not int values.

  2. A swap takes three assignments: copy one element to the temporary, copy the other element into the first, copy the temporary into the second. Use the elements themselves, not getters and setters.

  3. On pass a (counting from 0), the last a runners are already in place. Subtract the outer counter from the inner loop's limit.

Reflection: questions and model answers

  1. The starter sorted the times correctly and still produced a wrong leaderboard. In one or two sentences, what is the difference between sorting one field and sorting the records?

    Sorting only the seconds rearranges one field and separates it from the rest of each record. Sorting the Runner objects moves each runner's name and time together, so every record stays intact.

  2. With your shorter passes, how many comparisons would a field of 100 runners need? How many did the starter's version need?

    99 + 98 + ... + 1 = 4,950 comparisons. The starter makes 99 passes of 99 comparisons each, 9,801.

  3. The swap moves references, not the objects themselves. How many Runner objects exist before and after sortByTime() runs?

    Five in both cases. The sort only changes which array element refers to which Runner; no Runner is created, copied or destroyed.
