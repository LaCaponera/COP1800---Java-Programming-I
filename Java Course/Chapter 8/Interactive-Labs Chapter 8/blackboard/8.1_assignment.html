Lab 8.1: The food-truck log that crashes on Sunday

An array of n elements has subscripts 0 through n − 1, and its size can come from a variable

Estimated time: about 20 minutes. Reading: Ch. 8, section 8.1 (pp. 267–271).

You will be able to:

  • Declare an array variable and reserve its memory with new, sizing it from a variable
  • Map a person's numbering (Day 1, Day 2, ...) to array subscripts that start at 0
  • Predict when a subscript is out of bounds and read an ArrayIndexOutOfBoundsException message

How to complete it

  1. Open the lab page (8.1.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (SalesWeek.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; no typed numbers where the size of the week belongs.

The checks on the lab page give you feedback; they are not your grade.
