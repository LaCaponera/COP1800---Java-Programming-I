Lab 8.3: The grade book that forgets the sixth student

Loops with a variable subscript, the length field, and using only the filled part of an array

Estimated time: about 25 minutes. Reading: Ch. 8, section 8.3 (pp. 273–277).

You will be able to:

  • Process array elements in a loop whose subscript is a variable
  • Use the length field, not a typed number, as an array's capacity
  • Keep a count to process only the part of an array that holds real data
  • Explain why an enhanced for loop cannot change the elements it visits

How to complete it

  1. Open the lab page (8.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (QuizBook.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; every loop over scores has a limit that says what it means (count or scores.length), never a typed number.

The checks on the lab page give you feedback; they are not your grade.
