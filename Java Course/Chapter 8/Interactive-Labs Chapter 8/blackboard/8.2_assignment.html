Lab 8.2: The coffee board that sells a null for $0.0

Initialization lists create and fill an array at once; a new array starts with default values

Estimated time: about 20 minutes. Reading: Ch. 8, section 8.2 (pp. 271–273).

You will be able to:

  • Create and fill an array in one statement with an initialization list
  • Predict the default value of the elements of a new int, double and String array
  • Decide when an array should be filled with a list and when its default values are exactly right

How to complete it

  1. Open the lab page (8.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (CoffeeMenu.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; each initialization list is readable, with the sizes and prices in matching order.

The checks on the lab page give you feedback; they are not your grade.
