Lab 8.7: The race results that give Dev's time to Ana

A bubble sort compares neighbours and swaps whole objects, not just the field it sorts by

Estimated time: about 25 minutes. Reading: Ch. 8, section 8.7 (pp. 292–300).

You will be able to:

  • Swap two array elements with a temporary variable
  • Trace a bubble sort and explain why each pass can make one comparison fewer
  • Sort an array of objects by one field while swapping the objects as units

How to complete it

  1. Open the lab page (8.7.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (Leaderboard.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the swap is three clear assignments with a well-named temporary.

The checks on the lab page give you feedback; they are not your grade.
