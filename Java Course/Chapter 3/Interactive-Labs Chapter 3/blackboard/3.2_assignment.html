Lab 3.2: The vet clinic's lobby screen

The parts of a method header, public access, stubs and calling a method in another class

Estimated time: about 25 minutes. Reading: Ch. 3, section 3.2 (pp. 86–90).

You will be able to:

  • Name the parts of a method header: access specifier, static, return type, identifier and parentheses
  • Explain what public access allows that private does not
  • Fill in a stub: a method with a finished header and an empty body
  • Call a method in another class with its fully qualified name, ClassName.methodName()

How to complete it

  1. Open the lab page (3.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (VetClinic.java, LobbyScreen.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; method names start with a verb in camel case; named constants in all capitals.

The checks on the lab page give you feedback; they are not your grade.
