Lab 1.9: Read the docs: a better weather alert

Use the Java API documentation to find a method version the chapter didn't show

Estimated time: about 30 minutes. Reading: Ch. 1, section 1.9 (pp. 29–30).

You will be able to:

  • Find a class's page in the Java API documentation
  • Read a method summary to choose the version with the arguments you need
  • Use a constant from the documentation in your code
  • Explain how the API docs help you learn beyond the textbook

How to complete it

  1. Open the lab page (1.9.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (WeatherAlert.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; class and method names follow Java conventions.

The checks on the lab page give you feedback; they are not your grade.
