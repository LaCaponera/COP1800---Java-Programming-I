Lab 5.5: The bike dock that runs out too early

The logical AND and OR operators, complete expressions on both sides, and short-circuit evaluation

Estimated time: about 30 minutes. Reading: Ch. 5, section 5.5 (pp. 174–177).

You will be able to:

  • Combine two Boolean tests with && (both must be true) or || (at least one must be true)
  • Write a complete Boolean expression on each side of a binary logical operator
  • Predict which method calls are skipped by short-circuit evaluation
  • Order the operands of && so a method with a side effect runs only when it should

How to complete it

  1. Open the lab page (5.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (UnlockStation.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; dependent statements indented under their if, else or case; named constants instead of bare numbers in conditions.

The checks on the lab page give you feedback; they are not your grade.
