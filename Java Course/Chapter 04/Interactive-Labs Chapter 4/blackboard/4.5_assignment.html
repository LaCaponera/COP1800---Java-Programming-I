Lab 4.5: The shipping counter's labels

Classes as data types: passing objects to methods and returning them

Estimated time: about 25 minutes. Reading: Ch. 4, section 4.5 (pp. 128–131).

You will be able to:

  • Explain why a class you write is a programmer-defined, composite data type
  • Write a method whose return type is a class, and return an object from it
  • Write a method with an object parameter
  • Assign a returned object to a declared reference, as you would an int

How to complete it

  1. Open the lab page (4.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ShippingCounter.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; private fields and public methods; method names start with a verb in camel case; named constants in all capitals.

The checks on the lab page give you feedback; they are not your grade.
