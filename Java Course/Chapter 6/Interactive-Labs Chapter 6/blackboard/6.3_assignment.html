Lab 6.3: The fish market's ticket that starts at 2

Shortcut arithmetic operators: += for accumulating, and when prefix and postfix ++ give different values

Estimated time: about 20 minutes. Reading: Ch. 6, section 6.3 (pp. 210–214).

You will be able to:

  • Use the add and assign operator += to accumulate a total
  • Use ++ as a stand-alone statement to count events
  • Explain the value a prefix ++x and a postfix x++ produce inside a larger expression
  • Explain why count = count++; leaves count unchanged

How to complete it

  1. Open the lab page (6.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (FishMarketCounter.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; increments and accumulations written as stand-alone statements unless their value is needed; no assignment of a variable to its own postfix expression.

The checks on the lab page give you feedback; they are not your grade.
