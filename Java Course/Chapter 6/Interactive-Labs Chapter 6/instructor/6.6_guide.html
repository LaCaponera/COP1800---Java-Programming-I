COP1800 · Java Programming I · Lab 6.6

The boatyard's empty docks and nine paint changes

Objectives

  • Write a nested loop in which the inner loop is entirely contained in the outer loop and restarts for every outer iteration
  • Trace how many times an inner loop body runs: outer iterations times inner iterations
  • Decide which variable should control the outer loop: the one that should change least often
  • Explain why two nestings can do the same work in a different, and differently costly, order

Requirements

  1. R1 In printSlipMap(), the inner loop's control variable starts again at 1 inside the outer loop, so every dock lists all of its slips. (A for loop nested in the for loop is the clearest way.)
  2. R2 In paintAllStripes(), the outer loop varies the color and the inner loop varies the boat, so all stripes of one color are painted before the next paint is loaded.
  3. R3 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. Trace the starter's printSlipMap(3, 4). What is slip when the outer loop begins its second iteration, and what does Dock 2's line show?

    slip is 5. The inner test 5 <= 4 is false immediately, so Dock 2's line is just "Dock 2:" with no slips (and the same for Dock 3).

  2. In the starter's paintAllStripes(3), how many times is paintStripe() called, and how many times does the paint change?

    9 calls and 9 paint changes: red, white, blue for boat 1, then red again for boat 2, and so on, so every call loads a different paint.

Solution

Boatyard.java
public class Boatyard
{
    public static final int COLORS = 3;   // 1 red, 2 white, 3 blue

    // Given: which paint is in the spray gun, and how many times it was changed.
    private static int loadedColor = 0;
    private static int paintChanges = 0;

    public static String colorName(int color)
    {
        if(color == 1)
            return "red";
        else if(color == 2)
            return "white";
        else
            return "blue";
    }

    // Given: paints one stripe, loading a new paint only when the color changes.
    public static void paintStripe(int boat, int color)
    {
        if(color != loadedColor)
        {
            loadedColor = color;
            ++paintChanges;
            System.out.println("  (load " + colorName(color) + " paint)");
        }
        System.out.println("  boat " + boat + ": " + colorName(color) + " stripe");
    }

    public static void printSlipMap(int docks, int slipsPerDock)
    {
        for(int dock = 1; dock <= docks; ++dock)
        {
            System.out.print("Dock " + dock + ":");
            for(int slip = 1; slip <= slipsPerDock; ++slip)
            {
                System.out.print(" " + dock + "-" + slip);
            }
            System.out.println();
        }
    }

    public static void paintAllStripes(int boats)
    {
        loadedColor = 0;
        paintChanges = 0;

        for(int color = 1; color <= COLORS; ++color)
        {
            for(int boat = 1; boat <= boats; ++boat)
            {
                paintStripe(boat, color);
            }
        }

        System.out.println("Paint changes: " + paintChanges);
    }

    public static void main(String[] args)
    {
        printSlipMap(3, 4);
        paintAllStripes(3);
    }
}

Walkthrough

Slip map. In the starter, slip was set to 1 once, before the outer loop. Dock 1's inner loop raised it to 5; for Dock 2 the test 5 <= 4 was false at once, so the inner body never ran again. An inner loop's control variable must be initialized every time the outer loop starts a new iteration. Declaring it in an inner for header does that automatically and limits its scope to the inner loop. The inner loop is entirely inside the outer loop's braces; loops can be nested but can never overlap.

Paint order. Both versions call paintStripe() 3 × 3 = 9 times and paint the same 9 stripes. The difference is which variable changes least often: the outer loop's variable changes once per full run of the inner loop. With boats outside, the color changed on every call (9 loads, 3 hours of reloading); with colors outside, it changes 3 times. This is the book's mailing-label example: when switching something is costly, put that variable in the outer loop.

C1 · The inner counter restarts for every dock

Start the slip counter at 1 inside the dock loop, for example with for(int slip = 1; slip <= slipsPerDock; ++slip) as the inner loop. Initialized once before the outer loop, the counter is already past the last slip when Dock 2 begins, so the inner body never runs again.

Hint:

Where is slip when Dock 2 starts?

C2 · Colors in the outer loop, boats in the inner loop

Swap the loops: the outer loop varies color and the inner loop varies boat. The outer loop's variable changes least often, so the paint is loaded once per color instead of once per stripe.

Progressive hints

  1. Trace slip through the starter: what value does it hold when the outer loop begins its second iteration?

  2. For the paint, list the calls to paintStripe() in order for both nestings. In which list does the color change least often?

  3. Swapping two nested for headers keeps the body the same; only the order of the calls changes.

Reflection: questions and model answers

  1. Your paintAllStripes() calls paintStripe() the same number of times as the starter. What changed, and what is it worth if each paint change takes 20 minutes?

    The order of the calls. With colors outside, the paint changes 3 times instead of 9: 6 fewer loads, which saves 120 minutes (2 hours) on a 3-boat job. The outer loop's variable changes least often.

  2. How many times does System.out.println("Hi"); run in for(int x = 0; x < 4; ++x) for(int y = 0; y < 5; ++y) System.out.println("Hi");? Explain.

    20 times: the inner loop runs its 5 iterations for each of the outer loop's 4 iterations, 4 × 5.

  3. In the slip map, does it matter which loop is outside? What would the map look like with slips in the outer loop?

    Yes. Each println ends a line, so the outer loop decides what a line means. With slips outside, each line would hold one slip number across every dock (1-1 2-1 3-1), which is not a map of docks.
