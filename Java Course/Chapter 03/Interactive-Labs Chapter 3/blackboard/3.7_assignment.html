Lab 3.7: The farmers-market scale

Ambiguous calls, and why a return type can't tell overloads apart

Estimated time: about 25 minutes. Reading: Ch. 3, section 3.7 (pp. 107–108).

You will be able to:

  • Recognize a call that matches two overloads equally well, and make it an exact match
  • Explain why methods that differ only in return type are illegal
  • Explain why a potentially ambiguous pair of methods compiles until an ambiguous call is made

How to complete it

  1. Open the lab page (3.7.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (MarketScale.java).

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
