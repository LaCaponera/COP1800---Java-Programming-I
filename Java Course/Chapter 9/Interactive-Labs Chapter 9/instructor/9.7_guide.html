The promo loan that rewrote the legal notice

Objectives

  • Declare a method final so no subclass can override it
  • Explain why a static method is hidden rather than overridden, and call the parent's version by class name
  • Declare a class final so it can't be extended

Requirements

  1. R1 Loan.legalNotice() is declared final, and PromoLoan no longer tries to override it.
  2. R2 The static PromoLoan.category() returns Loan.category() followed by (promo), calling the parent's static method by its class name.
  3. R3 PromoLoan is a final class.
  4. R4 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. The starter compiles and the promo loan prints No fees, ever! Which keyword in Loan would have made the compiler refuse PromoLoan's override?

    final. Declaring legalNotice() final means no subclass may override it, so PromoLoan's version would be a compile error.

  2. PromoLoan's category() is static. Why can't it simply call super.category()?

    A static method belongs to the class and runs without an object, so it has no this and no super. The parent's static method is reached by class name: Loan.category().

Solution

Loan.java
public class Loan
{
    private double principal;
    private double annualRate;

    public Loan(double amount, double rate)
    {
        principal = amount;
        annualRate = rate;
    }

    // Simple interest: principal x rate x years.
    public double totalInterest(int years)
    {
        return principal * annualRate * years;
    }

    public static String category()
    {
        return "Personal loan";
    }

    // Wording approved by the compliance office.
    public final String legalNotice()
    {
        return "Fixed rate. Late fee $35.0 after 10 days.";
    }
}
PromoLoan.java
public final class PromoLoan extends Loan
{
    public PromoLoan(double amount, double rate)
    {
        super(amount, rate);
    }

    public static String category()
    {
        return Loan.category() + " (promo)";
    }
}

Walkthrough

A subclass cannot override a method declared final (p. 350); with final on legalNotice(), the marketing override no longer compiles, like Figures 9-25 and 9-26 (p. 351), so it has to go. A subclass cannot override a static method either; a static method with the same signature only hides the parent's (p. 348). A static method receives no this, so super.category() is not allowed (p. 349), but a child can call the parent's nonprivate static method by class name, Loan.category(), as Figure 9-21 does with BaseballPlayer.showOrigins() (p. 350). That is also why @Override must not be placed on the static method. A final class cannot be a parent (p. 351); Java's Math class is one (p. 352).

Messages students see when a check fails

C1 · The legal notice is final

Declare the method public final String legalNotice(). Then no subclass can replace the compliance wording.

C2 · PromoLoan doesn't override the notice

Delete PromoLoan's legalNotice() method. Once the parent's version is final, this override is a compile error, and every promo loan must show the approved notice.

C3 · The promo category builds on Loan's

Return Loan.category() + " (promo)". A static method can't use super, but it can call the parent's static method through the class name.

C4 · PromoLoan is a final class

Write the header as public final class PromoLoan extends Loan, so no class can extend PromoLoan and change the promo terms.

Progressive hints

  1. One keyword fixes R1 and another use of the same keyword fixes R3; R1 also means deleting a method.

  2. After adding final to legalNotice() in Loan, compile: the error tells you which method in PromoLoan must go.

  3. In a static method, reach the parent's static method with ClassName.methodName().

Reflection: questions and model answers

  1. Why is final a better protection for the legal notice than a comment saying “do not override”?

    The compiler enforces final: an override simply won't compile. A comment can be missed or ignored, which is what happened with the marketing version.

  2. Why is @Override not allowed on the static category() in PromoLoan?

    A static method can't override a parent method; it only hides it. @Override would tell the compiler it overrides something, so the compiler reports an error.

Extension
