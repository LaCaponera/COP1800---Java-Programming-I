Lab 9.7: The promo loan that rewrote the legal notice

final methods and final classes can't be overridden; static methods are hidden, not overridden

Estimated time: about 25 minutes. Reading: Ch. 9, section 9.7 (pp. 348–352).

You will be able to:

  • Declare a method final so no subclass can override it
  • Explain why a static method is hidden rather than overridden, and call the parent's version by class name
  • Declare a class final so it can't be extended

How to complete it

  1. Open the lab page (9.7.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Loan.java, PromoLoan.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; no @Override on the static method; final used only where the rules require it.

The checks on the lab page give you feedback; they are not your grade.
