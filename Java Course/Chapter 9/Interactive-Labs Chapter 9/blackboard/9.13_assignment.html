Lab 9.13: The beach heat alert that waits for 35 degrees

A record for fixed data, an anonymous inner class and a lambda for one-off rules

Estimated time: about 30 minutes. Reading: Ch. 9, section 9.13 (pp. 377–381).

You will be able to:

  • Replace a data-only class with a record and use its generated accessors, equals() and toString()
  • Implement an interface with an anonymous inner class that uses an effectively final variable
  • Implement a functional interface with a lambda expression

How to complete it

  1. Open the lab page (9.13.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Reading.java, Monitor.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; the anonymous class ends with a semicolon; no leftover HeatRule.

The checks on the lab page give you feedback; they are not your grade.
