Lab 9.8: The drone deliveries billed at $0.0

An abstract method forces every subclass to write its own version

Estimated time: about 25 minutes. Reading: Ch. 9, section 9.8 (pp. 352–359).

You will be able to:

  • Declare an abstract class that exists only to be extended
  • Declare an abstract method with no body that every concrete subclass must implement
  • Avoid overloading an abstract method by mistake instead of overriding it

How to complete it

  1. Open the lab page (9.8.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Delivery.java, DroneDelivery.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; @Override on the drone's fee(); no placeholder bodies left in Delivery.

The checks on the lab page give you feedback; they are not your grade.
