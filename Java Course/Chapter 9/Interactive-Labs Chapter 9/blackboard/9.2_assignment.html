Lab 9.2: The VIP who was sent to the general line

A subclass adds what only it needs; instanceof asks what an object is

Estimated time: about 25 minutes. Reading: Ch. 9, section 9.2 (pp. 332–336).

You will be able to:

  • Use extends so a subclass receives its parent's fields and methods
  • Put a field and its methods in the most specific class that needs them
  • Use instanceof to test whether an object is a member of a class

How to complete it

  1. Open the lab page (9.2.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Ticket.java, VipTicket.java, Gate.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; each member lives in the most specific class that needs it.

The checks on the lab page give you feedback; they are not your grade.
