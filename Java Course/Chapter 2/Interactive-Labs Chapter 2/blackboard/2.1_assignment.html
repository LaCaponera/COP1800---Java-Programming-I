Lab 2.1: The shift trade

One value at a time: swap two variables safely, and give a magic number a name

Estimated time: about 25 minutes. Reading: Ch. 2, section 2.1 (pp. 39–47).

You will be able to:

  • Declare a named constant with final and a conventional all-capitals name
  • Concatenate a constant's value into a string with +
  • Explain why a variable holds only one value at a time
  • Swap the values of two variables using a third, temporary variable

How to complete it

  1. Open the lab page (2.1.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (ShiftTrade.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; variables in camel case, named constants in all capitals.

The checks on the lab page give you feedback; they are not your grade.
