Lab 2.7: The ticket order dialogs

Input dialogs return Strings: parse them with type-wrapper classes; confirm dialogs return an int

Estimated time: about 30 minutes. Reading: Ch. 2, section 2.7 (pp. 64–67).

You will be able to:

  • Accept input with JOptionPane.showInputDialog(), in its one-argument and four-argument versions
  • Convert a String to a number with Double.parseDouble() and Integer.parseInt()
  • Ask a yes-or-no question with showConfirmDialog() and compare its result with JOptionPane.YES_OPTION
  • Explain why a dialog's answer can't be used in arithmetic until it's converted

How to complete it

  1. Open the lab page (2.7.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (TicketOrder.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; variables in camel case, named constants in all capitals.

The checks on the lab page give you feedback; they are not your grade.
