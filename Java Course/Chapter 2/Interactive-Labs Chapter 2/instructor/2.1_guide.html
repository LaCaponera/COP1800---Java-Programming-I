The shift trade

Objectives

  • Declare a named constant with final and a conventional all-capitals name
  • Concatenate a constant's value into a string with +
  • Explain why a variable holds only one value at a time
  • Swap the values of two variables using a third, temporary variable

Requirements

  1. R1 The shift length is a named constant, SHIFT_HOURS, declared once with final and the value 12.
  2. R2 All four board lines show the shift length by concatenating SHIFT_HOURS: no 12 typed inside a string.
  3. R3 The trade swaps the two start times through a third variable, without retyping 7 or 19.
  4. R4 The board matches the screen above exactly. (verified by the program output)

Before you code: warm-up and model answers

  1. Trace the starter's trade with ortizStart = 7 and leeStart = 19. What does each variable hold after ortizStart = leeStart;, and after leeStart = ortizStart;?

    After the first line both hold 19: the 7 in ortizStart is overwritten and gone. The second line copies 19 into leeStart, which already held 19, so both nurses end up starting at 19:00.

  2. The starter types 12 inside four strings. If the ward switches to 8-hour shifts, what would you have to do, and what could go wrong?

    Find and edit all four strings by hand. It's easy to miss one, or to change a 12 that means something else, and the compiler can't help because the numbers are just text inside strings.

Solution

ShiftTrade.java
public class ShiftTrade
{
    public static void main(String[] args)
    {
        final int SHIFT_HOURS = 12;
        int ortizStart = 7;
        int leeStart = 19;
        int temp;

        System.out.println("Before the trade");
        System.out.println("Ortiz starts at " + ortizStart + ":00 (" +
            SHIFT_HOURS + "-hour shift)");
        System.out.println("Lee starts at " + leeStart + ":00 (" + SHIFT_HOURS +
            "-hour shift)");

        temp = ortizStart;
        ortizStart = leeStart;
        leeStart = temp;

        System.out.println("After the trade");
        System.out.println("Ortiz starts at " + ortizStart + ":00 (" +
            SHIFT_HOURS + "-hour shift)");
        System.out.println("Lee starts at " + leeStart + ":00 (" + SHIFT_HOURS +
            "-hour shift)");
    }
}

Walkthrough

A variable holds one value at a time: ortizStart = leeStart; overwrites the 7, so the next line can only copy 19 back. Parking the 7 in temp first keeps it alive until leeStart receives it. SHIFT_HOURS is declared once with final, so a change to 8-hour shifts is one edit, and the compiler rejects any later attempt to assign it. To place its value in a sentence, the string is closed, + SHIFT_HOURS + is concatenated, and a new string continues.

Messages students see when a check fails

C1 · SHIFT_HOURS is a final int set to 12

Declare the constant with the keyword final before the type: final, int, the name SHIFT_HOURS, = 12 and a semicolon. final is what stops the value from ever being reassigned.

Hint:

The reading's examples, such as NUMBER_OF_DEPTS, show the order of the words.

C2 · Every board line concatenates SHIFT_HOURS

In all four board lines, end the string after :00 (, add + SHIFT_HOURS +, then start a new string with -hour shift). A 12 inside quotation marks is text the compiler can't connect to your constant.

Hint:

Count the lines that still contain 12-hour. Each one needs the same change.

C3 · The swap goes through a temporary variable

Use three assignments in a row: copy one start time into a third variable, overwrite that start time with the other one, then give the other one the saved value. The third variable is the only place the first value survives.

Hint:

Which value disappears on the starter's first trade line? Save that one before the line runs.

C4 · No value is lost or retyped

Remove the two-line attempt (ortizStart = leeStart; followed by leeStart = ortizStart;): after its first line both variables hold 19. And don't assign 7 or 19 directly: the program must trade whatever times the nurses had, not the ones you know today.

Progressive hints

  1. Trace the starter's two trade lines with real numbers: after the first line, what does ortizStart hold? What is left for the second line to copy?

  2. Before you overwrite a variable, store its current value in a variable nobody else changes. The reading calls it a temporary holding spot.

  3. To put a constant inside a sentence, close the string, concatenate the constant with + on both sides, and open a new string.

Reflection: questions and model answers

  1. Explain in your own words why the swap needs a third variable. Use the words "one value at a time".

    A variable holds one value at a time, so assigning a new value destroys the old one. To swap, one of the original values has to be copied into a third variable before it is overwritten; then it can be given to the other variable.

  2. Name two benefits of SHIFT_HOURS over typing 12, and say what the compiler does if a later line tries SHIFT_HOURS = 8;.

    The name says what the number means, and a change happens in one place instead of four; the compiler also catches a misspelled name, which it can't do for a mistyped 12. Because the constant is final, SHIFT_HOURS = 8; is a compiler error: a final variable can't be assigned again.

Extension

Add a third nurse, Park, who starts at 15:00, and rotate the times: Ortiz takes Lee's time, Lee takes Park's, and Park takes Ortiz's. How many extra variables do you need?
