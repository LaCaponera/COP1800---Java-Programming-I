The bike station with empty docks

Objectives

  • Explain why new Bike[4] creates four empty references and no bikes
  • Construct every object of an array in a loop
  • Call a method of one element: the subscript follows the array name, before the dot
  • Use the enhanced for loop with an array of objects

Requirements

  1. R1 The constructor builds one Bike per dock with new, numbered FIRST_ID + x for dock x.
  2. R2 ride() adds the miles to the bike in the given dock: the subscript follows bikes, before the dot.
  3. R3 totalMiles() adds up the miles of every bike using an enhanced for loop.
  4. R4 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. After bikes = new Bike[4];, how many Bike objects exist, and what does bikes[0] hold?

    None. The array holds four references and each one is null; bikes[0] stays null until a Bike is constructed and assigned to it.

  2. Which of these is legal Java, and why: bikes[2].getMiles() or bikes.getMiles()[2]?

    bikes[2].getMiles(). The subscript picks one Bike object from the array, then the dot calls that object's method. The array itself has no getMiles() method.

Solution

BikeStation.java
public class BikeStation
{
    public static final int FIRST_ID = 501;
    private Bike[] bikes;

    // A station with one bike in each dock: bike 501 in dock 0, 502 in dock 1, ...
    public BikeStation(int docks)
    {
        bikes = new Bike[docks];
        for(int x = 0; x < bikes.length; ++x)
            bikes[x] = new Bike(FIRST_ID + x);
    }

    // Records a trip on the bike in the given dock (docks are numbered from 0).
    public void ride(int dock, int miles)
    {
        bikes[dock].addMiles(miles);
    }

    // Miles ridden on all the station's bikes together.
    public int totalMiles()
    {
        int total = 0;
        for(Bike bike : bikes)
            total += bike.getMiles();
        return total;
    }

    public String report()
    {
        String text = "";
        for(int x = 0; x < bikes.length; ++x)
            text += "Bike " + bikes[x].getId() + ": "
                + bikes[x].getMiles() + " mi\n";
        return text;
    }
}

Walkthrough

new Bike[docks] reserves memory for references only; each element starts as null, the default for an array of objects (pp. 272, 278). Whether or not a class has a default constructor, you must call a constructor with new for each element (p. 280), usually in a loop like the book's emps[x] = new Employee(START_NUM + x, STARTING_SALARY); (p. 278). To call a method of one element, the subscript follows the array name and comes before the dot: bikes[dock].addMiles(miles) (p. 279). The enhanced for loop works with objects, too: bike refers to each element in turn, and no subscript or limit is needed (p. 279). Using docks instead of bikes.length as the loop limit also passes.

Messages students see when a check fails

C1 · Every dock gets its own Bike object

In a loop over the docks, construct each bike: bikes[x] = new Bike(FIRST_ID + x);. new Bike[docks] only made empty (null) references; every element needs its own new.

C2 · ride() calls the method of one bike

Call bikes[dock].addMiles(miles): the subscript chooses the bike, then the dot calls that bike's method.

C3 · totalMiles() uses an enhanced for loop

Use an enhanced for loop over bikes with a Bike loop variable, and add each bike's getMiles() to a total. The loop variable is each Bike in turn, so you need no subscript and no limit.

Progressive hints

  1. Creating an array of objects and creating the objects are separate steps, even for a class with a default constructor. You need one new Bike(...) for each element.

  2. In the constructor's loop, dock x gets the bike whose number is x more than FIRST_ID. Use the array's length (or docks) as the limit.

  3. In totalMiles(), an enhanced for loop whose variable has type Bike gives you each bike in turn. Ask each one for its miles and keep a running total.

Reflection: questions and model answers

  1. The crash happened in report(), but the mistake was in the constructor. Explain the connection.

    The constructor created the array but no Bike objects, so every element stayed null. report() was the first code to call a method through an element, and calling a method through a null reference throws a NullPointerException.

  2. In this class, what does bikes.length measure? If the docks also had names, String[] names = {"North", "Pier"};, what would names.length and names[0].length() be?

    bikes.length is the number of docks, the elements of the array. names.length is 2, the number of Strings; names[0].length() is 5, the number of characters in North. Arrays have a length field, Strings a length() method.

  3. When would you choose the enhanced for loop over a for loop with a subscript, and when can't you use it?

    Choose it to visit every element when the position doesn't matter, as in totalMiles(). You can't use it when you need the subscript, as for a dock number, or when you must store new objects in the elements, as in the constructor.
