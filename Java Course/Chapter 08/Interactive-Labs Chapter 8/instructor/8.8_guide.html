The theater that sells balcony seats it doesn't have

Objectives

  • Create and use a two-dimensional array with [row][column] subscripts
  • Use length for the number of rows and array[row].length for the length of one row
  • Build a jagged array whose rows have different lengths
  • Visit every element with nested loops

Requirements

  1. R1 The constructor creates one row per element of seatsPerRow and gives row r exactly seatsPerRow[r] seats: a jagged array.
  2. R2 freeSeats() counts the unsold seats with nested loops: rows up to taken.length, seats up to that row's own length.
  3. R3 bestRow() returns the row with the most unsold seats, the lower row number on a tie.
  4. R4 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. With the starter, taken = new boolean[4][10]. What are taken.length and taken[3].length, and what does taken[3][9] stand for in the real theater?

    taken.length is 4, the number of rows, and taken[3].length is 10. taken[3][9] would be the tenth balcony seat, which doesn't exist: the balcony has only 4 seats.

  2. In taken[row][seat], which subscript picks the row and which picks the seat? What does taken[0][5] = true mean?

    The first subscript is the row, the second is the seat in that row. taken[0][5] = true means seat 5 of row 0, the last seat of the front row, is sold.

Solution

SeatMap.java
public class SeatMap
{
    private boolean[][] taken;   // taken[row][seat] is true once the seat is sold

    // seatsPerRow[r] is the number of seats in row r; row 0 is nearest the stage.
    public SeatMap(int[] seatsPerRow)
    {
        taken = new boolean[seatsPerRow.length][];
        for(int row = 0; row < taken.length; ++row)
            taken[row] = new boolean[seatsPerRow[row]];
    }

    // Sells a seat; returns false if it was already sold.
    public boolean book(int row, int seat)
    {
        if(taken[row][seat])
            return false;
        taken[row][seat] = true;
        return true;
    }

    public int seatsInRow(int row)
    {
        return taken[row].length;
    }

    // Unsold seats in one row.
    private int freeInRow(int row)
    {
        int free = 0;
        for(int seat = 0; seat < taken[row].length; ++seat)
            if(!taken[row][seat])
                ++free;
        return free;
    }

    // Unsold seats in the whole theater.
    public int freeSeats()
    {
        int free = 0;
        for(int row = 0; row < taken.length; ++row)
            free += freeInRow(row);
        return free;
    }

    // The row with the most unsold seats; on a tie, the row nearer the stage.
    public int bestRow()
    {
        int best = 0;
        for(int row = 1; row < taken.length; ++row)
            if(freeInRow(row) > freeInRow(best))
                best = row;
        return best;
    }
}

Walkthrough

A two-dimensional array is an array of arrays: taken[row] is itself a one-dimensional array (p. 301). taken.length holds the number of rows and taken[row].length the number of seats in that row (p. 303), as in the book's DisplayRents (Figure 8-32). Because each row is a separate array, rows may have different lengths: declare the number of rows, leave the second size empty (new boolean[seatsPerRow.length][]), then create each row with its own size (p. 304, jagged arrays). New boolean elements start as false, so every seat starts unsold. Nested loops visit every element, and the inner limit must be the current row's length. The solution adds a private freeInRow() helper that both methods use. Comparing with > (not >=) in bestRow() keeps the lower row on a tie.

public class TestSeatMap
{
    public static void main(String[] args)
    {
        int[] rows = {6, 8, 8, 4};   // row 3 is the narrow balcony
        SeatMap hall = new SeatMap(rows);
        hall.book(0, 0);
        hall.book(0, 1);
        hall.book(1, 3);
        hall.book(3, 0);
        hall.book(3, 1);
        hall.book(3, 2);

        System.out.println("Seats in the balcony (row 3): " + hall.seatsInRow(3));
        System.out.println("Free seats: " + hall.freeSeats());
        System.out.println("Row with most free seats: " + hall.bestRow());

        int[] studioRows = {5, 7};
        SeatMap studio = new SeatMap(studioRows);
        studio.book(1, 0);
        studio.book(1, 1);
        System.out.println("Studio: " + studio.freeSeats() + " free, best row "
            + studio.bestRow());
    }
}

Messages students see when a check fails

C1 · Each row gets exactly the seats it has

Create the rows first with the second size left empty, taken = new boolean[seatsPerRow.length][];, then in a loop give each row its own size: taken[row] = new boolean[seatsPerRow[row]];. A rectangular [4][10] array invents seats the theater doesn't have.

C2 · freeSeats() visits every row and each row's own seats

Loop over the rows with row < taken.length, and inside it over that row's seats with seat < taken[row].length. The rows differ in length, so neither a typed number nor taken[0].length works for every row. (Counting one row in a helper method is fine.)

C3 · bestRow() compares every row

Loop over every row (row < taken.length), count each row's unsold seats, and keep the row with the most. Start with row 0 and replace it only when a row has strictly more, so a tie keeps the row nearer the stage.

Progressive hints

  1. A two-dimensional array is an array of arrays. You can create the array of rows first, leaving the second size empty, and then create each row separately with its own size.

  2. When rows differ in length, the inner loop's limit must be the current row's own length, not the first row's and not a typed number.

  3. bestRow() is a search for the largest value: start with row 0 as the best so far and replace it only when another row has strictly more unsold seats. A helper method that counts one row's unsold seats keeps both methods short.

Reflection: questions and model answers

  1. Why can't a rectangular new boolean[4][10] model this theater correctly, even if nobody ever books a seat that doesn't exist?

    Every row would have 10 elements, so anything that counts seats, such as freeSeats() or seatsInRow(), would count seats that don't exist: 4 extra in row 0, 2 in rows 1 and 2, and 6 in the balcony.

  2. In a nested loop over taken, what would go wrong with seat < taken[0].length as the inner limit, given these rows?

    Every row would be treated as 6 seats wide, the length of row 0. Seats 6 and 7 of rows 1 and 2 would be skipped, and the 4-seat balcony would throw an ArrayIndexOutOfBoundsException at seat 4.

  3. The theater opens a second hall. Where would you add a third subscript, and what would taken[1][3][0] mean?

    A hall number first: taken[hall][row][seat]. taken[1][3][0] would be seat 0 of row 3 in hall 1, the second hall.

Extension

Add bookBlock(int row, int count), which sells the first count adjacent unsold seats in a row and returns true, or sells nothing and returns false when the row has no such block. A family buying 4 tickets wants to sit together.
