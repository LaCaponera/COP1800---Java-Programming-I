Lab 8.8: The theater that sells balcony seats it doesn't have

A two-dimensional array is an array of rows, and every row has its own length

Estimated time: about 30 minutes. Reading: Ch. 8, section 8.8 (pp. 300–306).

You will be able to:

  • Create and use a two-dimensional array with [row][column] subscripts
  • Use length for the number of rows and array[row].length for the length of one row
  • Build a jagged array whose rows have different lengths
  • Visit every element with nested loops

How to complete it

  1. Open the lab page (8.8.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (SeatMap.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; loop variables named row and seat (not i and j) so the subscripts read clearly.

The checks on the lab page give you feedback; they are not your grade.
