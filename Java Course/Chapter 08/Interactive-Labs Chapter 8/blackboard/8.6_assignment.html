Lab 8.6: The greenhouse log that loses its Celsius readings

Array elements are passed by value; an array is passed as a copy of its reference

Estimated time: about 25 minutes. Reading: Ch. 8, section 8.6 (pp. 289–292).

You will be able to:

  • Explain why changing a parameter that received one array element doesn't change the array
  • Write a method that changes the caller's array through the reference it receives
  • Write a method that returns a new array and leaves its argument unchanged

How to complete it

  1. Open the lab page (8.6.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (SensorLog.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the new array has a name that says what it holds (for example fahrenheit).

The checks on the lab page give you feedback; they are not your grade.
