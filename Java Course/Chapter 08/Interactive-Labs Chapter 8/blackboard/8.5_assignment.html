Lab 8.5: The print shop that charges every order the small-job price

Searching parallel arrays, stopping early, and finding the range a value falls into

Estimated time: about 30 minutes. Reading: Ch. 8, section 8.5 (pp. 284–288).

You will be able to:

  • Search an array for a value and use the same subscript in a parallel array
  • Stop a search as soon as the item is found
  • Find the range a number falls into by comparing it with the ranges' lower limits (a range match)

How to complete it

  1. Open the lab page (8.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (PrintShop.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the loop counter is changed only in the for clause, or the early exit is otherwise easy to see.

The checks on the lab page give you feedback; they are not your grade.
