Lab 8.4: The bike station with empty docks

An array of objects holds references: every element needs its own new

Estimated time: about 25 minutes. Reading: Ch. 8, section 8.4 (pp. 277–283).

You will be able to:

  • Explain why new Bike[4] creates four empty references and no bikes
  • Construct every object of an array in a loop
  • Call a method of one element: the subscript follows the array name, before the dot
  • Use the enhanced for loop with an array of objects

How to complete it

  1. Open the lab page (8.4.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (BikeStation.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Consistent Allman braces and indentation; the loop variable in the enhanced for loop has a meaningful name.

The checks on the lab page give you feedback; they are not your grade.
