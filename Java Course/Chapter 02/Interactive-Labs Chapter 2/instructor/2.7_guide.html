The ticket order dialogs

Objectives

  • Accept input with JOptionPane.showInputDialog(), in its one-argument and four-argument versions
  • Convert a String to a number with Double.parseDouble() and Integer.parseInt()
  • Ask a yes-or-no question with showConfirmDialog() and compare its result with JOptionPane.YES_OPTION
  • Explain why a dialog's answer can't be used in arithmetic until it's converted

Requirements

  1. R1 The price typed in the first dialog is converted from String to double with Double.parseDouble().
  2. R2 The number of tickets comes from a four-argument input dialog (message How many tickets?, title Ticket order, QUESTION_MESSAGE) and is converted with Integer.parseInt().
  3. R3 The parking question uses a five-argument confirm dialog (message Add a parking pass?, title Parking, YES_NO_OPTION, QUESTION_MESSAGE), and wantsParking stores whether the result equals JOptionPane.YES_OPTION.
  4. R4 Running the test program produces exactly its expected output. (verified by the program output)

Before you code: warm-up and model answers

  1. In the starter, priceString holds what the customer typed, for example "27.25". Why can't the program simply write price = priceString; or total = priceString * tickets;?

    priceString is a String, text that happens to contain digits. A String can't be stored in a double or used in arithmetic, so it must first be converted to a number, with Double.parseDouble().

  2. Double.parseDouble(priceString) is called on the class name Double, not on an object. What does that tell you about the method?

    It is a static method: it belongs to the class and can be used without creating any object of that class.

Solution

TicketOrder.java
import javax.swing.JOptionPane;

public class TicketOrder
{
    public static void main(String[] args)
    {
        String priceString;
        String ticketsString;
        double price;
        int tickets;
        int parkingChoice;
        boolean wantsParking;
        double total;

        priceString = JOptionPane.showInputDialog(null, "Price per ticket?");
        price = Double.parseDouble(priceString);

        ticketsString = JOptionPane.showInputDialog(null,
            "How many tickets?", "Ticket order",
            JOptionPane.QUESTION_MESSAGE);
        tickets = Integer.parseInt(ticketsString);

        parkingChoice = JOptionPane.showConfirmDialog(null,
            "Add a parking pass?", "Parking",
            JOptionPane.YES_NO_OPTION, JOptionPane.QUESTION_MESSAGE);
        wantsParking = (parkingChoice == JOptionPane.YES_OPTION);

        total = price * tickets;
        System.out.println("Tickets: " + tickets + " at $" + price);
        System.out.println("Total: $" + total);
        System.out.println("Parking pass: " + wantsParking);
        JOptionPane.showMessageDialog(null, "Your total is $" + total +
            "\nParking pass: " + wantsParking);
    }
}

Walkthrough

showInputDialog() always returns a String, even when the user types digits, and a String can't be multiplied. The type-wrapper classes Double and Integer provide static parse methods that convert the text to a number. A cast can't do this: casts work only between primitive types, and String is a reference type. showConfirmDialog() returns an int naming the button clicked, so comparing it with JOptionPane.YES_OPTION produces the boolean. 27.25 × 4 is 109.0, which Java prints with one decimal place.

TestTicketOrder.java
import java.awt.Component;
import java.awt.Container;
import java.awt.Window;
import javax.swing.JDialog;
import javax.swing.JOptionPane;
import javax.swing.Timer;

public class TestTicketOrder
{
    // A customer's answers, in order: the price, the number of tickets,
    // Yes to the parking pass, and OK on the total.
    private static final Object[] ANSWERS =
        { "27.25", "4", JOptionPane.YES_OPTION, JOptionPane.OK_OPTION };
    private static int nextAnswer = 0;

    public static void main(String[] args)
    {
        System.out.println("TicketOrder starts; the test answers each dialog");
        // Every 0.7 seconds, answer whichever dialog is open.
        // You'll see each one appear and close.
        Timer helper = new Timer(700, e -> answerOpenDialog());
        helper.start();
        TicketOrder.main(new String[0]);
        helper.stop();
        System.out.println("TicketOrder finished");
        System.exit(0);
    }

    // You don't need to follow the rest yet: it finds the open dialog and answers it.
    private static void answerOpenDialog()
    {
        for (Window window : Window.getWindows())
        {
            if (window instanceof JDialog && window.isShowing())
            {
                JOptionPane pane = findPane(((JDialog) window).getContentPane());
                if (pane != null)
                {
                    Object answer = JOptionPane.OK_OPTION;
                    if (nextAnswer < ANSWERS.length)
                    {
                        answer = ANSWERS[nextAnswer];
                    }
                    nextAnswer++;
                    if (pane.getWantsInput())
                    {
                        pane.setInputValue(answer.toString());
                        pane.setValue(JOptionPane.OK_OPTION);
                    }
                    else if (answer instanceof Integer)
                    {
                        pane.setValue(answer);
                    }
                    else
                    {
                        pane.setValue(JOptionPane.OK_OPTION);
                    }
                    return;
                }
            }
        }
    }

    private static JOptionPane findPane(Container container)
    {
        for (Component child : container.getComponents())
        {
            if (child instanceof JOptionPane)
            {
                return (JOptionPane) child;
            }
            if (child instanceof Container)
            {
                JOptionPane found = findPane((Container) child);
                if (found != null)
                {
                    return found;
                }
            }
        }
        return null;
    }
}

Progressive hints

  1. Whatever the customer types, an input dialog gives you a String. Which classes did the reading use to turn a String into a number?

  2. The longer showInputDialog() takes four arguments and the longer showConfirmDialog() takes five. The extra ones are the title, the buttons and the icon.

  3. A confirm dialog doesn't return true or false: it returns a number for the button. Compare that number with the constant for Yes.

Reflection: questions and model answers

  1. You can cast a double to an int with (int). Why can't you convert the dialog's String with a cast such as (double) priceString?

    Casts convert only between primitive types such as int and double. A String is an object, a reference type, so a cast can't turn it into a number; the type-wrapper classes' parse methods are needed.

  2. What would wantsParking be if the customer chose No, and what number does the confirm dialog return in that case?

    wantsParking would be false, because the dialog returns JOptionPane.NO_OPTION, which is not equal to JOptionPane.YES_OPTION. The constants are int values identifying the button.
