The drone drop-off

Objectives

  • Declare float values with the F suffix
  • Explain why a floating-point literal is a double by default
  • Compare the significant digits of float (6 or 7) and double (14 or 15)
  • Choose double when a value needs more digits than a float keeps

Requirements

  1. R1 payloadKg is a float holding 2.35, written with the F suffix, and printed as Payload: 2.35 kg.
  2. R2 latitude and longitude are double values that keep all seven decimal places.
  3. R3 The log matches the screen above exactly. (verified by the program output)

Before you code: warm-up and model answers

  1. The starter stores the latitude 25.7616798 in a float. Predict what println shows, and explain the difference.

    It shows about 25.76168. A float keeps only six or seven significant digits, so the last digits of 25.7616798 are lost; the value is rounded to what a float can hold.

  2. Why does float payloadKg = 2.35; fail to compile, when double payloadKg = 2.35; is fine?

    A floating-point literal such as 2.35 is a double by default. Storing a double in a float could lose precision, so the compiler refuses (possible lossy conversion). Writing 2.35F makes the literal a float to begin with.

Solution

DroneDrop.java
public class DroneDrop
{
    public static void main(String[] args)
    {
        float batteryVolts = 11.1F;
        float payloadKg = 2.35F;

        double latitude = 25.7616798;
        double longitude = -80.1917902;

        System.out.println("Battery: " + batteryVolts + " V");
        System.out.println("Payload: " + payloadKg + " kg");
        System.out.println("Drop-off latitude: " + latitude);
        System.out.println("Drop-off longitude: " + longitude);
    }
}

Walkthrough

25.7616798 has nine significant digits; a float keeps only six or seven, so it prints 25.76168 and the drone aims for a nearby point instead. A double keeps 14 or 15 digits, more than enough. The literal 2.35 is a double by default, so storing it in a float needs the F suffix; without it the compiler reports a possible lossy conversion from double to float. The coordinates need no suffix once they are double (a D is allowed but unnecessary).

Reflection: questions and model answers

  1. The battery and payload stay float, but the coordinates became double. State the rule you used to decide, in one or two sentences.

    Count the significant digits the value really needs. If six or seven are enough, as for 11.1 V or 2.35 kg, a float saves memory; if it needs more, as the nine-digit coordinates do, use a double, which keeps 14 or 15.

  2. Your program now prints the coordinates correctly. Does that mean a double stores 25.7616798 exactly? Explain what the reading says about floating-point values.

    Not necessarily. Floating-point numbers are often only approximations, because many decimal fractions can't be represented exactly in binary. A double is close enough that it prints all seven decimals, but it may still differ from the exact value far beyond them.
