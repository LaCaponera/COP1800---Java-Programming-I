The boarding pass

Objectives

  • Store single characters in char variables with single quotation marks
  • Use the escape sequences \n, \" and \\ in string literals
  • Explain why "Seat: " + 14 + 'C' and 14 + 'C' give different results
  • Store and display a character's Unicode value

Requirements

  1. R1 firstInitial and seatLetter are char variables holding 'M' and 'C'.
  2. R2 BOARDING PASS and the passenger line come from one println() call, using an escape sequence.
  3. R3 The gate line shows "B7" with its quotation marks, using an escape sequence.
  4. R4 int seatCode stores the Unicode value of seatLetter, and the pass prints it.
  5. R5 The last line shows the path C:\passes\rivera.txt, using an escape sequence for each backslash.
  6. R6 The pass matches the screen above exactly. (verified by the program output)

Before you code: warm-up and model answers

  1. Once seatLetter is the char 'C' (Unicode 67), what does System.out.println(seatRow + seatLetter); print? Compare it with "Seat: " + seatRow + seatLetter.

    It prints 81: with no string involved, + adds the numbers, and the char counts as its Unicode value, 14 + 67. In "Seat: " + seatRow + seatLetter the string comes first, so each + is concatenation, from left to right, giving "Seat: 14C".

  2. Why can't you write the gate line as "Gate: "B7""?

    The second double quotation mark ends the string after Gate: , so B7 would be read as code and the line wouldn't compile. A quotation mark that must appear in the output is written as the escape sequence \".

Solution

BoardingPass.java
public class BoardingPass
{
    public static void main(String[] args)
    {
        String lastName = "Rivera";
        char firstInitial = 'M';
        int seatRow = 14;
        char seatLetter = 'C';
        String gate = "B7";
        int seatCode = seatLetter;

        System.out.println("BOARDING PASS\nPassenger: " + lastName + ", " +
            firstInitial + ".");
        System.out.println("Seat: " + seatRow + seatLetter);
        System.out.println("Gate: \"" + gate + "\"");
        System.out.println("Seat letter code: " + seatCode);
        System.out.println("Saved to C:\\passes\\rivera.txt");
    }
}

Walkthrough

A char holds exactly one character and its literal uses single quotation marks. \n starts a new line inside a single string, \" puts a double quotation mark inside a string without ending it, and \\ stands for one backslash (a lone backslash would start an escape sequence). Assigning a char to an int stores its Unicode value: 'C' is 67. In "Seat: " + seatRow + seatLetter the string comes first, so both + signs concatenate and the result is "Seat: 14C"; seatRow + seatLetter on its own would add 14 and 67.

Messages students see when a check fails

C1 · firstInitial and seatLetter are chars

Declare both as char and use single quotation marks: 'M' and 'C'. Double quotation marks make a String, which can't be stored in a char.

C2 · The first two lines come from one println with \n

Delete the separate BOARDING PASS statement and start the passenger line's string with BOARDING PASS, then the newline escape sequence, then Passenger: . The escape sequence is a backslash followed by n.

Hint:

Figure 2-14 prints two lines with a single call.

C3 · The gate is printed inside escaped quotation marks

A plain " would end the string, so write each quotation mark that must appear as \": one right after Gate: , and one after the gate.

Hint:

The first escaped quote goes inside the first string; the second needs a string of its own after + gate +.

C4 · seatCode stores the seat letter's Unicode value

Declare int seatCode and assign it seatLetter. Every character is stored as a number, and assigning a char to an int keeps that number: its Unicode value.

C5 · The seat code is printed

Print Seat letter code: followed by seatCode, after the gate line.

C6 · Each backslash in the path is escaped

Inside a string a single backslash starts an escape sequence, so each backslash that must appear is written as two: \\. The path has two of them.

Progressive hints

  1. Single characters live in single quotation marks; strings in double ones. Change both the type and the quotation marks.

  2. Table 2-6 lists the escape sequences. You need three of them: one for a new line, one for a double quotation mark, one for a backslash.

  3. For the Unicode value you need no new syntax: an int variable can receive a char. Table 2-5 tells you what to expect for C.

Reflection: questions and model answers

  1. The path needs \\ for each backslash. What would "C:\passes\rivera.txt" (single backslashes) do instead?

    Each single backslash would start an escape sequence with the next letter: \p isn't valid, so the compiler reports an illegal escape character. (\r would even be read as a carriage return.) Doubling it gives one literal backslash.

  2. Printing two lines with one println() and \n versus two println() calls: the reading says each has an advantage. What are they?

    One call with \n is shorter to type and calls the method once; two separate calls can be easier to read because each output line has its own statement. (A text block is a third option.)

Extension

Replace the first println() with a text block (three double quotation marks) that holds the first two lines. What changes about how you write the line break?
