Lab 11.6: The seat map that books only one seat

FileChannel positions, ByteBuffer wrap and rewind

Estimated time: about 25 minutes. Reading: Ch. 11, section 11.6 (pp. 461–463).

You will be able to:

  • Explain the difference between sequential and random access
  • Write bytes at chosen positions with a FileChannel, position() and a wrapped ByteBuffer
  • Reuse a ByteBuffer with rewind(), and read a single byte from any position

How to complete it

  1. Open the lab page (11.6.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (SeatMap.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; one position and one rewind per seat; every channel closed.

The checks on the lab page give you feedback; they are not your grade.
