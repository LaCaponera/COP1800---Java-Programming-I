Lab 13.5: The sensor log that keeps half its errors

Loop with the enhanced for, and remove safely with an Iterator

Estimated time: about 25 minutes. Reading: Ch. 13, section 13.5 (pp. 528–529).

You will be able to:

  • Process every element of a collection with an enhanced for loop, without an index
  • Create an Iterator with iterator() and loop with hasNext() and next()
  • Remove elements during a loop with the iterator's remove() instead of an index

How to complete it

  1. Open the lab page (13.5.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (SensorLog.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers explain the skipped element and the iterator, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; next() is called once per pass; no unused index variables.

The checks on the lab page give you feedback; they are not your grade.
