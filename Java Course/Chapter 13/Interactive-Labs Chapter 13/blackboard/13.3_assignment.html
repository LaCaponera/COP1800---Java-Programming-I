Lab 13.3: The race results that reshuffle the entry list

Store objects in an ArrayList and sort them with Comparable

Estimated time: about 30 minutes. Reading: Ch. 13, section 13.3 (pp. 514–524).

You will be able to:

  • Store objects of your own class in an ArrayList and remove one by its position
  • Make a class sortable by implementing Comparable and overriding compareTo()
  • Sort with Collections.sort() without destroying an order the program still needs

How to complete it

  1. Open the lab page (13.3.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code files (Runner.java, Leaderboard.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers are specific to this code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; @Override on compareTo(); the copy has a clear name.

The checks on the lab page give you feedback; they are not your grade.
