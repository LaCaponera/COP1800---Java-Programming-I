Lab 13.4: The help desk that always serves the newest ticket

Choose a LinkedList when items keep joining and leaving at the front

Estimated time: about 20 minutes. Reading: Ch. 13, section 13.4 (pp. 524–527).

You will be able to:

  • Describe how a doubly-linked list stores each element with the addresses of the elements before and after it
  • Decide between ArrayList and LinkedList from how a program moves its data
  • Use add(0, ...), remove(0) and isEmpty() to build a fair, first-come queue

How to complete it

  1. Open the lab page (13.4.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (HelpDesk.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers compare ArrayList and LinkedList with this queue in mind, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; the empty check comes before remove().

The checks on the lab page give you feedback; they are not your grade.
