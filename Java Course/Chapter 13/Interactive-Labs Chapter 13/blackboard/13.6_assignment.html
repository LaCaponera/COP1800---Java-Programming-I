Lab 13.6: The hold shelf that only takes books

Write one generic class instead of a copy for every type

Estimated time: about 25 minutes. Reading: Ch. 13, section 13.6 (pp. 530–532).

You will be able to:

  • Declare a generic class with a type parameter section, class Slot<T>
  • Use the type parameter T for a field, a parameter and return types
  • Instantiate the same generic class with different reference types, and explain why a primitive can't be used

How to complete it

  1. Open the lab page (13.6.html) from this module. Your work saves automatically in your browser.
  2. Answer the short warm-up about the code you are given, then write your code until every structure check passes.
  3. Run the test program (instructions are on the lab page), paste its output back into the page and compare.
  4. Answer the reflection questions in your own words.
  5. Download (or copy) your lab report.

Submit here: the lab report (.txt) and your code file (Slot.java).

How it will be assessed

  • Requirements met (5 pts): All structure checks pass and the test program's output matches (see the lab report).
  • Reasoning (3 pts): Warm-up and reflection answers compare generic and non-generic code, in the student's own words.
  • Style (2 pts): Allman braces and indentation kept; one type parameter named T used consistently.

The checks on the lab page give you feedback; they are not your grade.
