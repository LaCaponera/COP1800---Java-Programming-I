The sensor log that keeps half its errors

Objectives

  • Process every element of a collection with an enhanced for loop, without an index
  • Create an Iterator with iterator() and loop with hasNext() and next()
  • Remove elements during a loop with the iterator's remove() instead of an index

Requirements

  1. R1 removeErrors() loops with an Iterator<Integer> (iterator(), hasNext(), next()) and removes each error with the iterator's remove(), never with readings.remove().
  2. R2 average() adds the readings with an enhanced for loop; no get() call.
  3. R3 above(limit) returns the readings greater than limit, in order, separated by single spaces (an empty string if there are none), using an enhanced for loop or an iterator and no get().
  4. R4 Running the test program prints exactly what it expects. (verified by the program output)

Before you code: warm-up and model answers

  1. Trace the starter's removeErrors() on [21, -1, -1, 23]. At x = 1 the first -1 is removed. What is at position 1 now, and what position does the loop check next?

    The second -1 slides into position 1, but ++x makes the loop check position 2 (23) next, so the second -1 is never examined and survives.

  2. An iterator offers three methods. Which one removes an element, and which element does it remove?

    remove(). It removes the last element returned by next().

Solution

SensorLog.java
import java.util.*;

public class SensorLog
{
    private static final int ERROR = -1;
    private LinkedList<Integer> readings = new LinkedList<Integer>();

    public void record(int value)
    {
        readings.add(value);
    }

    // Removes every error reading and returns how many were removed.
    public int removeErrors()
    {
        int removed = 0;
        Iterator<Integer> iter = readings.iterator();
        while (iter.hasNext())
        {
            if (iter.next() == ERROR)
            {
                iter.remove();
                ++removed;
            }
        }
        return removed;
    }

    // The average of the readings.
    public double average()
    {
        int sum = 0;
        for (int value : readings)
            sum += value;
        return (double) sum / readings.size();
    }

    // The readings above limit, in order, separated by spaces.
    public String above(int limit)
    {
        String result = "";
        for (int value : readings)
            if (value > limit)
                result += value + " ";
        return result.trim();
    }

    public String toString()
    {
        return readings.toString();
    }
}

Walkthrough

An iterator is an object that loops through the elements of a collection (p. 528). iterator() returns one; hasNext() reports whether another element exists, next() returns it, and remove() removes the last element next() returned (p. 529). Because the iterator keeps its own place, removing never makes it skip an element, unlike the index loop, where remove(x) shifts the next -1 into position x just before ++x moves past it. The enhanced for (foreach) loop creates an iterator behind the scenes (p. 528), so average() and above() need neither size() nor get(); the book notes an iterator avoids looking up the size and, on a linked list, avoids following links from the start for every get(x). iter.next() == ERROR compares an Integer with an int constant, so Java unboxes the Integer and compares numbers. Building the string with a trailing space and calling trim() gives single spaces with nothing at the end.

TestSensorLog.java
public class TestSensorLog
{
    public static void main(String[] args)
    {
        SensorLog log = new SensorLog();
        int[] raw = {21, -1, -1, 23, 19, -1, 22};
        for (int value : raw)
            log.record(value);

        System.out.println("Raw: " + log);
        System.out.println("Errors removed: " + log.removeErrors());
        System.out.println("Clean: " + log);
        System.out.println("Average: " + log.average());
        System.out.println("Above 20: " + log.above(20));
        System.out.println("Above 25: [" + log.above(25) + "]");
    }
}

Messages students see when a check fails

C1 · removeErrors() uses an Iterator

Create Iterator<Integer> iter = readings.iterator(); and loop while (iter.hasNext()), getting each reading with iter.next().

C2 · The iterator does the removing

Call iter.remove() (no argument) to delete the reading next() just returned. readings.remove(x) shifts the list under an index and skips the next element.

C3 · average() uses an enhanced for

Write for (int value : readings) and add value to the sum. No index and no get(): each reading is visited once.

C4 · above() walks the list without get()

Loop with for (int value : readings) and add each value greater than limit to the result.

C5 · above() compares with limit

Keep a reading only when it is greater than limit (value > limit). Equal readings are not above it.

Progressive hints

  1. In removeErrors(), the for loop and its index go away. Ask the iterator whether another reading exists as the loop condition, and fetch the reading inside the loop.

  2. Calling next() twice in one pass skips a reading. Store iter.next() in a variable if you need the value more than once.

  3. In above(), add value + " " to the result for each match and return result.trim(), or put the space before every value except the first.

Reflection: questions and model answers

  1. Why can't removeErrors() simply use for (int value : readings) and call readings.remove(...) inside it? What does that tell you about when you need an explicit Iterator?

    The foreach loop's hidden iterator notices that the list changed behind its back and throws ConcurrentModificationException. You need your own Iterator when you remove while looping, because only its remove() keeps it in step.

  2. The greenhouse now wants a second pass that removes readings above 40. After removeErrors() has finished, can you reuse the same Iterator object? What does the book say to do?

    No. That iterator has reached the end, and there is no reset. Create a new Iterator with readings.iterator() (p. 529).

Extension

Add int removeSpikes(int jump) that uses an iterator to remove any reading that differs from the previous kept reading by more than jump degrees, and returns how many it removed. Keep the previous value in a variable as you go.
